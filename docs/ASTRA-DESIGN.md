## 요청과 기존 지침의 관계

사용자 요청: 기존 디자인은 Claude 모드로 보존하고 Astra 모드를 비교하며 기본 디자인을 설정한다. 흑백 위주의 디자인을 색상·이미지·동작이 있는 서비스 공통 디자인으로 발전시킨다.
이번 Astra 시안은 기존 `DESIGN.md`의 검정 주요 버튼·새 색상 금지·5단계 글자 크기 제한에 대한 명시적 대안이다. 이 문서는 시안에만 적용한다. 기존 `CLAUDE.md`, `DESIGN.md`, 운영 CSS와 화면은 변경하지 않는다.

## 원칙

- 색은 기능을 구분한다. 코발트는 주요 행동과 t-box, 민트는 커뮤니티, 앰버는 주의, 빨강은 삭제·실패다.
- 읽는 면은 밝고 조용하게, 입구와 주요 행동은 선명하게. 업무 표와 문서 본문에는 장식 배경을 깔지 않는다.
- 공통 토큰·부품으로 서비스 전역을 확장한다. Astra 규칙은 `data-design="astra"` 아래로 한정한다.
- 한국어 중심, 선 아이콘, 외부 CDN·폰트·라이브러리·API 호출 없음. 장식은 저장소 안 SVG와 CSS로 표현한다.
- 색만으로 상태를 전달하지 않는다. 키보드 초점, 44px 누름 영역, 줄어든 모션, 고대비와 좁은 화면을 지원한다.

## 동작과 저장 범위

- 상단 Claude/Astra 전환은 현재 시안만 바꾼다. 최초 기본값은 Claude다. 공유 주소 `?design=astra`는 저장된 기본값보다 우선하는 일회성 미리보기다.
- `기본으로 저장`은 현재 디자인을 `qaredi.preview.design`에 저장한다. 설정 화면에서도 선택·저장 가능하다. 시안용 이름공간으로 운영 설정과 충돌하지 않는다.
- 밝음/어두움/기기 설정, 고대비와 움직임 줄이기는 독립적인 시안 설정이다. 저장소 접근이 차단되면 현재 탭에서는 동작하며 저장 실패를 표시한다.
- 화면 이동은 주소 해시, 브라우저 뒤로/앞으로를 지원한다. 검색은 예시 파일·문서를 실제로 걸러 준다. 파일 올리기와 글 쓰기는 로컬 시연임을 명시하며 서버에 전송하지 않는다.
- 예시 사용자·문서·파일 수치는 가상이며 운영 데이터에 접근하지 않는다. 기본값은 이 브라우저의 시안에만 해당하며 관리자 전역 기본값 또는 계정 동기화가 아니다.
- Claude 모드는 원본 `app.css`를 그대로 복사한 `claude.css`를 사용한다. 같은 예시 콘텐츠 비교이며 운영 화면의 완전한 복제는 아니다.

## 전역 적용 시 별도 확인

`shell_top.php`, 로그인, 런처에 허용 목록을 거친 디자인 속성과 설정 로딩을 연결하고 Claude를 기본으로 둔다. 서버가 첫 HTML에 디자인을 넣어 깜빡임을 막는다. 기존 `tbox_theme`와 고대비 계정 설정을 보존한다. 런처의 스크립트 정책과 문서 팔레트 대비 계산 상수는 디자인 확대에 맞춰 별도 검토한다. 운영 권한·라우팅·DB·인증 로직은 시안에서 건드리지 않는다.
