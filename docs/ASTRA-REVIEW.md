## ② 주의할 범위

- Claude 모드는 원래 CSS를 적용한 **같은 예시 콘텐츠의 비교**다. 실제 운영 화면을 스냅샷으로 복제한 것이 아니다. 운영 Claude 디자인은 그대로 있다.
- 기본 디자인은 이 브라우저의 시안 기본값이다. 서비스 공통 또는 계정 기본값과 동기화하지 않는다.
- 작성한 예시 문서와 선택한 파일 정보는 메모리에만 존재하며 새로고침하면 사라진다. 로그인도 실제 인증이 아니다.
- 기존 앱의 팔레트 대비 계산은 기존 배경값에 의존한다. 전역 채택 시 배경 토큰 변경과 함께 별도 검토해야 한다.

## ③ 미검증

- 실제 데이터·역할별 화면에 Astra를 적용한 회귀. 이 단계는 예시 화면 검토다.
- Safari·Firefox 및 실제 휴대폰 실기기. Chromium에서 반응형 너비를 검증했다.
- 보조기기를 사용한 전체 접근성 감사, 실제 파일 업로드·인증·서버 저장. 해당 기능의 운영 코드를 바꾸지 않았다.
- 사용자 디자인 채택 여부 및 서비스 전역 적용은 대기.

## ④ 다음 조치

시안에서 디자인 방향을 확인한 뒤, 채택된 토큰과 부품을 공통 셸·로그인·런처부터 실제 화면으로 연결한다. 기본값 범위(브라우저/계정/사이트)를 확정하고 서버 렌더링, 기존 다크 모드·고대비, 문서 팔레트 대비 계산과의 통합을 검증한다. 사용자 확인 전에 이 전역 적용을 진행하지 않는다.
