# Qaredi 디자인 평가와 개선안 — 2026-10-01

운영 웹의 파일·내 계정·내 활동·관리·계정·조직·권한·감사·휴지통 9개 화면을 1440px에서 확인하고, 새 테마는 실제 PHP 뷰를 렌더한 360·412·820·1440px 화면에서 비교했다. 이 평가는 디자이너의 주관적 시각 평가다. 사용자 인터뷰나 작업 시간 측정 결과는 아니다.

## 현재 수준

기존 Claude 디자인은 **6/10**. 운영 도구의 일관성과 기본 구조는 갖췄지만 Qaredi만의 인상과 정보 우선순위가 부족하다. 흑백 자체가 문제는 아니다. 브랜드 이름·주요 동작·보조 제어가 비슷한 강도로 보여 중요한 것이 빠르게 눈에 들어오지 않는다.

| 관점 | 주관 평가 /10 | 관찰한 근거 |
|---|---:|---|
| 일관성 | 8 | 같은 셸·버튼·패널·배지를 반복해 학습 비용이 낮다. 다크·고대비 토큰이 있다. |
| 브랜드 | 4 | t-box 이름이 작은 사이드바 텍스트이고 Qaredi의 고유 시각 자산이 부족하다. |
| 시각 위계 | 6 | 제목과 업로드 버튼은 구분되지만 여러 테두리 상자가 비슷한 무게로 경쟁한다. |
| 데이터 가독성 | 5 | 실제 파일 화면에서 긴 파일명이 줄바꿈되고 작업 아이콘이 두 줄이다. 폴더 안내가 본문보다 강하게 반복된다. |
| 마감 | 7 | 공간·선·아이콘이 정돈되어 있으나 빈 상태·브랜드 표현·동작 피드백의 개성이 약하다. |

색과 브랜딩을 반영한 새 시안의 시각 완성도 목표는 **8/10**이다. 아래의 작업 흐름 개선까지 끝나야 제품 전체의 사용성이 그 수준에 도달했다고 평가할 수 있다.

## 이번에 배포하는 디자인

| 테마 | 방향 | 추천 용도 |
|---|---|---|
| Claude | 기존 zinc 흑백 원본 | 기존 디자인과 비교 |
| Astra | 코발트·민트, 밝고 명확한 작업 공간 | 기본 업무용 |
| Aurora | 에메랄드·골드, 차분한 깊이 | 장시간 사용하는 개인 취향 |
| Bloom | 코랄·크림, 부드러운 따뜻함 | 밝고 편안한 개인 취향 |
| Nova | 잉크·민트·핑크·보라, 빛과 궤도 | 가장 화려한 시그니처 디자인 |

Nova를 이번 작업의 대표안으로 선택했다. 런처는 큰 문구와 Q 아트를 중심으로 구성하고, 업무 도구 카드에 t-box·커뮤니티 이름을 크게 배치했다. 실제 업무 화면은 선택 색을 활성 내비·브랜드·주요 버튼에 이어 쓴다. 로그인도 같은 시각 언어를 사용한다. 문서·표 자체에는 자동 모션을 넣지 않는다.

QAREDI와 주요 앱 이름은 Nova에서 색의 빛이 흐르고, 주요 버튼은 광택과 hover 반응을 준다. 아트는 짧은 궤도 모션으로 들어온다. 자동 모션은 최대 4.5초 한 번 후 끝난다. 기기의 reduced-motion 및 「움직임 줄이기」로 끌 수 있고 고대비에서는 장식을 억제한다. 5초 이상 자동으로 움직이는 콘텐츠는 멈출 수 있어야 한다는 [W3C 설명](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)을 설계에 반영했다.

테마 선택은 런처·로그인·공통 사이드바·내 계정에서 연다. 선택 즉시 현재 화면을 미리 보고, 「기본으로 저장」하면 브라우저의 Qaredi 전체에 적용된다. 저장 전 닫으면 원래 선택으로 돌아간다. 계정별 고대비와 브라우저별 테마는 설명을 분리했다.

## 웹 사례에서 가져온 판단

- [Stripe](https://stripe.com/): 직접 첫 화면을 확인했다. 큰 문구·눈에 띄는 주 동작과 생동감 있는 컬러 아트가 함께 있다. Qaredi에는 색의 생동감과 주 동작의 구분을 응용했다. 마케팅 페이지의 규모를 업무 표에 그대로 옮기지는 않는다.
- [Vercel Geist](https://vercel.com/geist/introduction): 컴포넌트·색·아이콘을 하나의 시스템으로 다루며 일관된 웹 경험을 목표로 한다. 테마마다 화면을 따로 복제하는 대신 하나의 구성 요소와 토큰 계층으로 유지하는 판단에 참고했다.
- [Linear](https://linear.app/)와 [Quality](https://linear.app/quality): 제품 개발 흐름을 중심에 놓고 제품 품질을 다룬다. 홈페이지는 직접 열었으나 첫 캡처에 본문 애니메이션이 로드되지 않아 시각 색채 평가의 근거에서는 제외했다. 불필요한 반복보다 작업 흐름의 품질을 개선해야 한다는 제품 관점만 참고했다.

## 검증 범위

`tests/design_themes.php`: 잘못된 쿠키 값(배열·대문자·속성 주입 포함)과 유효 값 19개. `tests/design_themes_browser.py`: 5테마 × 2밝기 × 4폭 × 6화면, 중복 ID·가로 넘침·기본 대비·비공개 앱 비노출·선택/취소/저장/이동/초점·OS dark/reduced-motion·고대비·자동 모션 종료. 인증/API 스크립트를 제외한 뷰 검사이며 실제 운영 회귀와 별도다. 정확한 결과는 `docs/design-themes-results.json`과 배포 검토 이력에 기록한다.

대표 캡처는 `docs/theme-shots/`에 있다. 모바일 Safari 실기기, 모든 사용자 문서의 임의 팔레트 조합, 장시간 성능, 화면 낭독기의 실제 음성 출력을 전부 검증한 것은 아니다. 기본 토큰 대비 통과를 서비스 전체 WCAG 준수로 표현하지 않는다.

최종 결과: 뷰 브라우저 1,090/0, 실제 운영 브라우저 252/0, 허용 목록 19/0, 공개 런처 61/0(운영 DB 대조 1개 건너뜀), 도움말 16/0, 부품 버전 37/0, 린트/위키 문제 0. 전체 런처의 인증·공유 쓰기 시험은 최근 사용자 활동 4건으로 운영 관문을 존중해 실행하지 않았다. 공개 HTTPS 저장/새로고침과 Secure 쿠키도 확인했다.
