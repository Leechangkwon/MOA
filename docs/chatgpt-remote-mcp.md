# ChatGPT에서 모아 연결하기

상태: 원격 MCP 개발 후보. 이 문서와 코드가 Git2에 있다는 사실만으로 운영 주소나 현재 채팅이 연결된 것은 아닙니다. 서버 적용과 실제 ChatGPT 계정에서 연결 시험을 마친 뒤 사용합니다.

## 어떤 연결인가요

ChatGPT가 모아의 허용한 도구를 호출해 내 기록을 읽고 저장합니다. 모아에 OpenAI API 키를 넣거나, 내 ChatGPT 로그인 토큰을 복사해 붙여 넣는 방식이 아닙니다. 답변은 사용하는 ChatGPT에서 만들며 해당 계정의 기능/사용 한도를 따릅니다. 기존 모아의 Gemini 사진 글쓰기, GPT API 메신저, PC 로컬 비서는 별도 기능입니다.

이 연결에서는 본인 기록만 읽고 수정합니다. 다른 사람이 공개한 글이라도 이 도구로 읽지 않습니다. 글 삭제, 사진 원본 변경, 공개 범위 변경, 새 공유 링크 발급은 제공하지 않습니다. 새 글은 비공개로 저장됩니다. 이미 공개된 글을 수정하면 기존 공개 범위 안에서 바뀐 글이 보이므로 저장할 내용을 먼저 확인하세요.

## 서버 적용 뒤 처음 연결하기

1. 모아에 로그인하고 **내 계정 → ChatGPT 연결**을 엽니다. ‘서버 준비 중’이면 아직 연결할 수 없습니다.
2. 화면의 MCP 연결 주소를 복사합니다. 운영 APP_URL이 `https://changkwon.mso.so`이면 주소는 `https://changkwon.mso.so/mcp`입니다. 이 주소에 토큰을 붙이지 않습니다.
3. 웹 ChatGPT에서 앱/연결 관리 화면을 열어 사용자 정의 MCP 앱을 추가합니다. 해당 계정에 개발자 모드 또는 사용자 정의 앱 생성 권한이 제공되어야 하며, 조직 계정은 관리자 정책이 적용될 수 있습니다. 실제 메뉴명과 모바일 제공 범위는 계정·클라이언트에 따라 확인해야 합니다.
4. 연결 주소를 넣고 OAuth 인증을 선택합니다. 모아 로그인 화면이 열리면 기존에 쓰던 비밀번호/OTP 또는 등록한 패스키 로그인 절차를 진행합니다.
5. 모아 승인 화면에서 현재 계정과 요청한 권한을 확인합니다. 사진을 읽히려면 사진 읽기, 글을 저장하려면 글 저장, 여행 계획을 다루려면 해당 여행 권한을 선택합니다. 읽기만 승인해도 시작할 수 있습니다.
6. ChatGPT로 돌아와 연결된 모아 앱을 선택한 대화에서 먼저 “모아에서 내가 누구로 연결됐는지 확인해 줘”를 요청합니다. 실제 계정 확인이 성공해야 연결된 것입니다.
7. 같은 계정의 휴대폰 ChatGPT에서 모아 앱/도구가 제공되는지 확인하고 기록 하나를 읽는 시험을 합니다. 이 항목이 제공되지 않으면 코드 배포만으로 모바일 앱 지원을 보장할 수 없습니다. 지원되는 웹 클라이언트에서 사용합니다.

사진은 요청한 글에 현재 첨부된 사진만 한 장씩 축소본으로 전달합니다. 사진 원본 파일은 모아에 보존하며 이미지의 파일 메타데이터를 제거합니다. 사진 자체에 보이는 사람·장소·글자는 모델에 전달됩니다. 영상 분석·새 이미지 생성/업로드·사진 편집은 이 연결의 기능이 아닙니다.

## 이렇게 요청해 보세요

- “내 최근 여행 기록을 찾아 줘. 제목과 날짜부터 보여 줘.”
- “이 기록에 첨부된 사진을 보고 오늘의 행복했던 순간을 짧게 정리해 줘. 사진에서 알 수 없는 일은 지어내지 말고, 저장 전 먼저 보여 줘.”
- “방금 고른 문장으로 이 글을 수정해 줘. 사진과 공개 범위는 유지해 줘.”
- “내 여행 계획을 읽고 내일 일정을 여유롭게 바꾼 안을 보여 줘. 내가 선택한 안으로만 저장해 줘.”

쓰기 권한을 허용하면 연결 앱의 유효한 저장 요청이 실행됩니다. 저장 전 미리보기를 요청하고 ChatGPT의 확인 절차를 사용하세요. 모아가 매 저장마다 별도 승인창을 강제로 여는 방식은 아닙니다.

다른 창에서 수정한 글이나 계획이 있으면 저장 충돌이 납니다. 최신 내용을 다시 읽고 사용자의 변경을 확인한 뒤 저장해야 합니다. 자동으로 덮어쓰지 않습니다.

## 권한·연결 해제

모아의 같은 연결 화면에서 승인한 연결을 확인하고 해제합니다. 해제하면 그 연결의 접근/갱신 자격이 더 이상 통하지 않습니다. 이미 ChatGPT 대화에 전달한 글이나 사진은 회수되지 않습니다. ChatGPT 쪽 앱 해제와 대화 관리는 해당 서비스에서 합니다.

비밀번호 변경·관리자 인증 초기화·계정 비활성 등 보안 상태가 바뀌면 다시 연결해야 할 수 있습니다. 연결이 끊겨도 기존 모아 기록을 지우지 않습니다.

## 운영자가 확인할 사항

- 실제 변경/검사/마이그레이션과 배포 절차는 `docs/work-items/chatgpt-remote-mcp.md`를 따릅니다.
- 기능은 기본 비활성입니다. APP_URL을 정확한 HTTPS origin으로 설정하고, 실제 ChatGPT가 사용하는 OAuth callback URI를 **정확히** 등록해야 합니다. 와일드카드·임의 도메인·요청자가 지정한 URL 자동 허용은 하지 않습니다.
- 이 클라우드는 Git2만 접근할 수 있어 최신 ChatGPT 설정 화면 및 공식 온라인 문서를 직접 확인하지 못했습니다. 운영 등록 시 공식 ChatGPT 사용자 정의 앱/MCP 안내와 실제 callback URI를 대조합니다.
- TLS 앞단을 포함한 접근/오류 로그에 OAuth query, code, state, token, Authorization 헤더와 요청/응답 본문이 기록되지 않도록 검증합니다. nginx 정책 파일 반영만으로 외부 프록시 로그까지 검증됐다고 하지 않습니다.
- OAuth 완료뿐 아니라 권한별 글/사진 읽기, 승인한 본문 저장, 여행 저장, 충돌, 연결 회수, 재연결까지 실제 ChatGPT로 확인해야 합니다.
