# ChatGPT에서 모아 연결하기

원격 연결 주소는 `https://changkwon.mso.so/mcp`입니다. 플러그인 설치와 모아 계정 연결은 별도 단계입니다. 설치 목록의 켜짐 표시만으로 연결 완료라고 판단하지 않습니다. 운영 상태와 검증 결과는 `docs/work-items/mcp-chatgpt-activation.md`와 `docs/work-items/moa-host-compat.md`를 확인합니다.

## 어떤 연결인가요

ChatGPT가 모아의 허용한 도구를 호출해 내 기록을 읽고 저장합니다. 모아에 OpenAI API 키를 넣거나, 내 ChatGPT 로그인 토큰을 복사해 붙여 넣는 방식이 아닙니다. 답변은 사용하는 ChatGPT에서 만들며 해당 계정의 기능/사용 한도를 따릅니다. 기존 모아의 Gemini 사진 글쓰기, GPT API 메신저, PC 로컬 비서는 별도 기능입니다.

이야기·여행 도구는 본인 기록만 읽고 수정합니다. 업무 문서 도구는 본인에게 읽기·편집 권한이 있는 프로젝트와 문서를 다룹니다. 다른 사람이 공개한 글이라도 이 도구로 읽지 않습니다. 글 삭제, 사진 원본 변경, 공개 범위 변경, 새 공유 링크 발급은 제공하지 않습니다. 새 글은 비공개로 저장됩니다. 이미 공개된 글을 수정하면 기존 공개 범위 안에서 바뀐 글이 보이므로 저장할 내용을 먼저 확인하세요.

## 이미 ZIP을 설치했다면

2026-10-18: **1.0.0을 설치한 ChatGPT 데스크톱 Codex·Work에서 실제 도구가 없었다면 먼저 1.0.1로 갱신합니다.** 기존 파일의 서버 확장 설정을 Codex가 읽지 못하는 문제가 실제 로더에서 재현됐습니다. [1.0.1 ZIP](https://changkwon.mso.so/tbox/assets/plugins/moa-community-records-1.0.1.zip)을 압축을 풀지 않고 기존 개인 플러그인의 새 버전 업로드에 사용합니다. ZIP의 계정 저장과 집 PC가 새 판을 불러왔는지는 별도 확인합니다. 같은 @ 선택·새 대화·토큰 재발급만 반복해 해결되는 문제로 안내하지 않습니다.

1. 설치한 **모아 커뮤니티 기록** 플러그인을 엽니다. 상세 화면에 **MCP 서버 → Moa**가 있으면 서버 설정이 포함된 것입니다. 별도 MCP 목록에 보이지 않는다는 이유만으로 같은 항목을 다시 만들지 않습니다.
2. 새 대화에서 `@`로 **모아 커뮤니티 기록**을 선택하고 “모아에 누구로 연결됐는지 확인해 줘”라고 요청합니다. 계정 연결 안내가 나오면 진행합니다. 연결 관리 항목의 위치·이름은 앱 버전에 따라 다를 수 있습니다.
3. **모아 로그인 화면**에서 평소 로그인 방법으로 로그인합니다. 이어 나오는 권한 승인 화면에서 업무 프로젝트·문서 읽기와 업무 문서 갱신 범위를 확인합니다. 기존 승인에는 새 권한이 자동 추가되지 않습니다.
4. ChatGPT로 돌아와 실제 계정 이름이 확인되면 “모아의 업무 프로젝트 목록을 보여 줘”로 읽기를 확인합니다. 문서 갱신은 대상을 선택하고 원하는 수정 내용을 요청한 뒤 진행합니다.

프로그램 토큰을 이 연결에 복사할 필요는 없습니다. 1.0.1 적용 후에도 실제 도구가 없다면 호스트의 로더 상태를 확인합니다. `unknown MCP server 'moa'`는 해당 호스트가 그 이름을 등록하지 않았다는 뜻이며 서버 장애나 토큰 오류를 확정하지 않습니다. 도구의 실제 이름에는 호스트가 붙인 접두사가 있을 수 있습니다. 설정 주소만 있고 계정 조회가 실패하면 아직 연결 완료가 아닙니다.

## 처음 등록한다면

ChatGPT 플러그인의 **사용자 지정 MCP 서버 추가**에서 위 HTTPS 주소와 OAuth 인증을 사용합니다. 계정·조직 정책에 따라 사용자 지정 연결 권한이 필요할 수 있습니다. 서버 준비 중(503)이면 운영자가 먼저 활성화해야 합니다. 플러그인이 만들어지면 위의 계정 연결·조회 순서로 확인합니다. 공식 절차: https://developers.openai.com/plugins/deploy/connect-chatgpt

현재 ZIP처럼 MCP 설정을 포함해 가져온 플러그인은 공식 정책상 Desktop only입니다. 휴대폰·웹의 서버 연결에는 등록 앱을 참조하는 별도 설정이 필요합니다. 데스크톱 성공만으로 모바일 사용까지 보장하지 않습니다. https://learn.chatgpt.com/docs/enterprise/plugin-management

사진은 요청한 글에 현재 첨부된 사진만 한 장씩 축소본으로 전달합니다. 사진 원본 파일은 모아에 보존하며 이미지의 파일 메타데이터를 제거합니다. 사진 자체에 보이는 사람·장소·글자는 모델에 전달됩니다. 영상 분석·새 이미지 생성/업로드·사진 편집은 이 연결의 기능이 아닙니다.

## 이렇게 요청해 보세요

- “내 최근 여행 기록을 찾아 줘. 제목과 날짜부터 보여 줘.”
- “이 기록에 첨부된 사진을 보고 오늘의 행복했던 순간을 짧게 정리해 줘. 사진에서 알 수 없는 일은 지어내지 말고, 저장 전 먼저 보여 줘.”
- “방금 고른 문장으로 이 글을 수정해 줘. 사진과 공개 범위는 유지해 줘.”
- “내 여행 계획을 읽고 내일 일정을 여유롭게 바꾼 안을 보여 줘. 내가 선택한 안으로만 저장해 줘.”

쓰기 권한을 허용하면 연결 앱의 유효한 저장 요청이 실행됩니다. 저장 전 미리보기를 요청하고 ChatGPT의 확인 절차를 사용하세요. 모아가 매 저장마다 별도 승인창을 강제로 여는 방식은 아닙니다.

다른 창에서 수정한 글이나 계획이 있으면 저장 충돌이 납니다. 최신 내용을 다시 읽고 사용자의 변경을 확인한 뒤 저장해야 합니다. 자동으로 덮어쓰지 않습니다.

## 권한·연결 해제

모아의 같은 연결 화면에서 승인한 연결을 확인하고 해제합니다. 해제하면 그 연결의 접근/갱신 자격이 더 이상 통하지 않습니다. 이미 ChatGPT 대화에 전달한 글이나 사진은 회수되지 않습니다. ChatGPT 쪽 앱 해제와 대화 관리는 해당 서비스에서 합니다.

비밀번호 변경·관리자 인증 초기화·계정 비활성 등 보안 상태가 바뀌면 다시 연결해야 할 수 있습니다. 연결이 끊겨도 기존 모아 기록을 지우지 않습니다.

## 운영자가 확인할 사항

- 실제 변경/검사/마이그레이션과 배포 절차는 `docs/work-items/chatgpt-remote-mcp.md`를 따릅니다.
- 기능은 기본 비활성입니다. APP_URL을 정확한 HTTPS origin으로 설정하고, 실제 ChatGPT가 사용하는 OAuth callback URI를 **정확히** 등록해야 합니다. 와일드카드·임의 도메인·요청자가 지정한 URL 자동 허용은 하지 않습니다.
- 2026-10-16 공식 인증 문서 확인: RFC9207을 광고하고 성공·거절 응답에 동일한 `iss`를 반환하는 서버의 새 적격 ChatGPT 클라이언트는 `https://chatgpt.com/connector_platform_oauth_redirect`를 사용합니다. 이 정확한 한 주소만 허용합니다. 기존 클라이언트는 metadata 갱신 또는 다시 연결이 필요할 수 있으며, 다른 callback은 실제 요청 확인 없이 추측해 허용하지 않습니다. https://developers.openai.com/plugins/build/auth
- TLS 앞단을 포함한 접근/오류 로그에 OAuth query, code, state, token, Authorization 헤더와 요청/응답 본문이 기록되지 않도록 검증합니다. nginx 정책 파일 반영만으로 외부 프록시 로그까지 검증됐다고 하지 않습니다.
- 데스크톱 Codex·Work의 native OAuth 복귀는 `MCP_OAUTH_LOOPBACK_ENABLED=1`일 때 정확한 `http://127.0.0.1[:port]/callback`만 추가 허용합니다. 등록·승인 단계의 포트 차이는 RFC8252로 허용하되, code 교환은 실제 승인 URI와 완전 일치해야 합니다. 기본값은 0입니다. localhost·다른 IP·다른 경로·query/fragment·임의 HTTP URL은 거부합니다. 기존 HTTPS 목록을 와일드카드로 바꾸지 않습니다. https://learn.chatgpt.com/docs/extend/mcp
- OAuth 완료뿐 아니라 권한별 글/사진 읽기, 승인한 본문 저장, 여행 저장, 충돌, 연결 회수, 재연결까지 실제 ChatGPT로 확인해야 합니다.
