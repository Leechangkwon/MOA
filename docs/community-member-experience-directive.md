## 목표와 결정

1. 초대 가입의 OTP는 선택. 비밀번호로 가입하고 OTP 또는 기기 패스키(지문/얼굴/기기 잠금)를 따로 등록한다. 기존 관리자 강제 정책과 관리자가 지정한 복구 절차는 유지한다. 이미 등록한 OTP는 비밀번호 로그인 시 계속 검증하고 패스키 로그인은 독립 경로다.
2. 비서 설치와 토큰은 선택. 모바일·PC 웹앱 설치를 실제 작동 경로로 제공한다. 기존 로그인 세션을 사용하는 웹앱에는 별도 토큰 복사가 필요 없다. Windows 독립 비서 배포물은 실제 존재·호환성이 확인될 때만 다운로드 링크를 제공하고 확인되지 않은 연결을 성공으로 표현하지 않는다.
3. 커뮤니티 입구는 전체 기능 안내. 업무 공간·개인 기록·공유 피드·메신저·파일을 구분하고 기존 바로가기 보존.
4. 팔로우 관계와 소유자 공개 범위를 서버에서 판정. 공유 피드는 팔로잉 중심, 발견 피드는 소유자가 명시적으로 공개한 기록만 순위화. 기존 공개 게시물의 공개 의미는 보존하고 비공개 기록을 자동 공개하지 않는다.
5. 스토리 카드의 배경/글자 테마 쌍을 수정한다.
6. 첫 가입 시 사용법 안내 여부를 선택. 화면을 어둡게 하고 현재 대상을 강조하며 순서·건너뛰기·다시 보기·키보드를 지원한다. 안내는 실제 게시/발송/권한 변경을 수행하지 않는다.
7. 여행 계획: 일정·장소·메모·진행 상태를 유연하게 수정하고 기록에 계획/일정을 선택적으로 연결한다. 개인 소유 검증, 원문 보존. MCP는 독립 범위로 읽기·쓰기 구분, 기존 문서 토큰 권한을 몰래 확장하지 않는다.
8. 스토리는 대표 사진과 짧은 요약을 기본으로 하고 전체 사진/본문은 상세 모달에서 본다. 내용 더 보기·댓글·좋아요·공유 아이콘에는 접근 가능한 이름을 준다.
