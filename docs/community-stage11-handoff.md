# 커뮤니티 11단계 구현 인계

상태: 11-A~C 구현·격리 검증, 통합 독립 검토 대기. 이 작업 사본에서 운영 DB·서비스·업무 자료를 변경하지 않았습니다. 커밋·발행·운영 배포는 메인 에이전트가 담당합니다.

## 사용 방법

- 데이터베이스의 **폼 · 일정 · 차트 추가**에서 뷰를 만들고, **뷰 설정**으로 수정합니다. 폼 질문의 순서·필수·조건, 응답 대상·익명·접수·알림을 설정합니다. 폼 주소를 복사해 전달하고 응답하면 같은 DB의 행으로 저장됩니다.
- 익명 응답은 일반 팀원에게 **익명 응답**으로 보입니다. DB 담당자·관리자·감사 기록에는 실제 응답자가 남습니다. 지난 응답의 익명 설정은 유지됩니다.
- 캘린더·타임라인은 날짜 속성 또는 기한을 사용합니다. 편집자는 일정을 끌거나 좌우 화살표로 옮깁니다. 같은 DB 관계를 선후행으로 설정하면 순환 연결을 막습니다.
- 차트는 막대·선·도넛·숫자와 개수·합계·평균을 지원합니다. 페이지 더보기에서 **대시보드로 표시**하고 **데이터베이스 뷰** 블록을 최대 12개 넣습니다. 담당자·기간 거르개는 적용 가능한 속성에만 적용됩니다.

## 구현 경계

폼 제출은 `forms_helpers.php::community_insert_page()`를 일반 행 생성과 공유합니다. 제출 관문은 독립되며 DB 행 잠금 뒤 현재 설정을 재조회합니다. 조건에 숨은 답변은 검증 전에 버리고, 1시간 30회·하루 1,000회는 삭제된 응답까지 셉니다. 개인 DB 응답은 비공개이며 비익명 제출자에게 필요한 경우 보기 공유만 부여합니다.

원본 `form_anonymous` 값은 응답마다 고정됩니다. `community_form_identity_hidden()`는 현재 DB 담당자/Admin을 확인하고 출력 메타데이터만 가립니다. canonical 행을 인가·감사 전에 바꾸지 않습니다. 페이지·판·이력·알림·목록·검색·내보내기·절차서 목록을 검사합니다.

기간 조회와 차트 집계는 공통 SQL 행 가시성 조건 안에서 실행됩니다. 속성·연산자·집계·버킷은 허용 목록, 실제 키와 값은 바인딩입니다. 기간은 최대 400일, 일정 500행 + truncated, 그룹 50개 + 그 밖, 평균의 잔여 그룹은 가중 평균입니다. 선후행 검사는 DB 잠금 아래 재귀 CTE(깊이 50 제한)로 하며 값 수정과 기존 관계의 선후행 활성화 모두 검사합니다.

문서 단계 9의 `db_view`는 UUID + v8hex만 받으며 중첩을 포함해 최대 12개입니다. 없는 DB와 읽을 수 없는 DB는 동일 카드입니다. 서버는 카드, 화면은 현재 인가를 통과한 자료를 표시합니다. 내보내기는 읽을 수 있는 이름만 기록합니다.

## 데이터·통합

마이그레이션: `db/migrations/2026-10-02_community_db_views.sql`. `form_view_id TEXT`, `form_anonymous BOOLEAN`, 상관 CHECK와 인덱스, 기존 enum을 보존하는 dashboard/form_response 추가입니다. 신규 테이블·운영 권한 확대는 없습니다. 새 DB와 이전 스키마에 반복 적용할 수 있게 작성했습니다.

10단계 `community_save_doc`는 메인 통합 시 반영하며 문서 저장 로직을 복제하지 않았습니다. 12단계 공개 폼은 actor=NULL 생성 경계 및 public_form_response 제약을 별도 패치합니다. 11단계 자체는 로그인 없는 요청을 허용하지 않습니다. public 플래그와 공개 UI를 이 변경에 섞지 않았습니다.

## 재현·증거

`python3 tests/community/stage11_harness.py --suite stage11_forms.py --output /새/격리/출력경로` 형태입니다. foundation/forms/views/limits/privacy/integrity/browser를 선택할 수 있습니다. 전용 `tbox_stage11_test_*` DB, 포트 8668/8669, 5개 합성 계정, private 임시 저장소를 생성하고 종료 시 제거합니다. 운영 계정은 연결 키만 읽어 새 테스트 DB에 연결하며 운영 레코드를 복사하지 않습니다. 브라우저 정적 자산은 test-only router가 nginx assets 별칭을 재현합니다.

각 실행의 HTTP 원문·결과 JSON·DB 적용 로그 및 화면은 이 사본의 부모 폴더에 있습니다. 최종 집계·명령·SHA 목록은 `stage11-final-evidence.json`과 `stage11-source-manifest.json`을 참조하세요. 원래 운영 주소가 박힌 공통 8묶음/과거 모든 community 스크립트를 무조건 실행하지 않았습니다. 전체 단계 통합 및 공개 HTTPS 운영 검증은 이 격리 검증과 구분합니다.
