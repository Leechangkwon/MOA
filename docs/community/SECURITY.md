## 1. 실습에서 뚫린 5가지 — 이 앱에서 하나씩

| # | 공격 | 1차 방어 | 2차 방어 | 확인 |
|---|---|---|---|---|
| 1 | 프론트 권한 우회 (남의 글 수정·삭제, 게시판 만들기) | 라우트 정책 필수(`post.write`·`board.manage`) + 핸들러 행 단위 `Authz::decidePostChange`·`decidePostCreate` | 재인증 관문(게시판 관리), 403 동일 문구, `authz.route deny` 기록 | T-8·T-9·T-12 |
| 2 | 권한 없는 데이터 노출 (팀·관리자 게시판) | `Authz::visibleWhere(u,'b')` — SQL `WHERE` 에서 제외 | 글·댓글은 게시판 행 `decideRead` 를 먼저, 없는 게시판 = 403 같은 문구 | T-7 |
| 3 | XSS (글·댓글 본문) | **평문만**(에디터·마크다운 없음) + 서버 HTML 에 사용자 내용 0 + `textContent` | CSP `script-src 'self'`(nginx + PHP 이중), 제어문자는 `\n` 만, 린트(innerHTML 금지) | T-10·T-13 |
| 4 | SQL 인젝션 (검색·정렬·페이지) | `Db::run` Prepared Statement 만, `ILIKE … ESCAPE '#'` 바인딩 | `ORDER BY` 허용 목록 → 고정 조각, `Http::query*` 로 값 좁힘, 오류 은닉(500 일반 문구) | T-11 |
| 5 | SSRF | **해당 기능이 없다.** `curl_*`·소켓·`file_get_contents('http')` 0줄 | `allow_url_fopen=Off`·`disable_functions`, 린트에 예외 파일 없음 | T-13 |
| + | CSRF (댓글·삭제 POST) | 상태 변경 메서드에 `X-CSRF-Token`(HMAC, 세션별) | 쿠키 `SameSite=Lax`, 401/403 기록 | T-11 |

## 2. 5가지 외의 위험 — 이 앱에서 새로 생기는 것부터

T-2·T-3 으로 실측. nginx `comm_login` 속도 제한 |
| 2 | R-02 | 커뮤니티에서 만든 잠금이 **t-box 의 살아 있는 세션**을 끊지 못한다 | 중간 | ◐ 위험 수용(Q-5) | t-box 는 자기 잠금에서 세션을 회수한다(R-48). 커뮤니티는 t-box `sessions` 에 권한이 없어 못 한다 | 받아들인다 — 세션 회수 권한을 주는 것(S-08 위반)보다 낫다. 30분 유휴·8시간 만료가 상한. 재검토: 관문 ③ |
| 3 | R-03 | `search_path` 로 표를 찾는다 — `community` 스키마에 `users` 가 생기면 **조용히 그쪽이 읽힌다** | 중간 | ✅ 실측(T-5 `to_regclass` 5표 의도대로, 린트 (h) 0건) | 로그인·권한이 가짜 표를 보게 되는 경로 | 린트 규칙 (h): `db/*.sql` 에 `CREATE TABLE (community\.)?(users|teams|permissions)` 가 있으면 반려. ## 3. 판정 요약 (설계 시점)

| 질문 | 답 |
|---|---|
| 5가지가 이 설계대로 만들면 막히는가 | **예.** t-box 와 같은 코드 경로를 복사하고, SSRF 는 기능 자체가 없다 |
| 계정 공유가 t-box 를 약하게 만드는가 | **최소 권한(S-08)과 잠금 공유(R-01)를 지키면 아니다.** 실측 필수: T-2·T-3·T-5·T-6 |
| 가장 먼저 확인할 것 | T-6(t-box 백업·회귀 불변) → T-5(권한 부정 확인) → T-2·T-3(잠금·코드 공유) |

## 4. 구현 후 재검토 절차 (반드시 실행으로 확인)

t-box `SECURITY.md` 4장과 같다: ① 영향받는 T-xx **전부 실행** ② `scripts/security_lint.sh` 0건 ③ 못 돌린 항목은 「미검증」 ④ 보고는 ① 안전한 이유(증거) ② 불안전한 이유 ③ 미검증 ④ 다음 조치 ⑤ 이 문서 7장에 한 줄, R-xx 상태 갱신. 검토 계정은 t-box 와 같은 `qa_*` 5개, UA `community-review/<날짜>`. **t-box 회귀(`stage26.sh`·`help_button.sh`)를 함께 돌린다** — 이 앱의 모든 검토에서 G-4 는 항목이다.
