## 2. 창구 — `PATCH /api/users/{uid}` 의 `username`

- **누가**: 라우트 정책 `user.manage`(Admin) + 재인증 관문(15분 창 — `Authz::REAUTH_POLICIES`, 역할 바꾸기와 같은 흐름 · 토큰 창구 집합 밖이라 `X-API-Token` 으로는 닿지 않는다) · CSRF · 사유 `reason_text` 필수 · 자기 자신 금지(`Authz::decideUserChange` — `self_change`).
- **함께 보낼 수 있는 칸**: `reason_text`(필수)·`display_name` 만. 역할·팀·활성·만료와 섞으면 400 — 감사 행이 늘 `user.update` 가 되게(섞인 요청이 「역할을 바꿨습니다」 행에 묻히지 않게).
- **규칙 = 계정 만들기와 같은 표**(같은 함수):

| 새 아이디 | 계정 만들기 | 아이디 바꾸기 |
|---|---|---|
| 형식 밖(2자 · 65자 · 대문자 · 빈칸 · 빗금 · 빈 글자 · 숫자 값 · 줄바꿈 끝·가운데 — 12장) | 400 `bad_request` | 400 `bad_request`(문구만 「아이디 형식이 맞지 않습니다 — 소문자·숫자·_ . - 로 3~64자입니다」) |
| 이미 있음(검토 계정 이름 포함 — 이미 있음이 먼저) | 400 `already_exists` | 400 `already_exists` |
| 대소문자만 다른 중복 | 400 `bad_request`(대문자는 형식 오류) | 같다 — DB 에도 소문자 이름만 있다(CHECK `users_username_chars`) · 비교는 그래도 `lower()` |
| `claude_`·`qa_` 접두 | 400 `reserved_prefix` | 400 `reserved_prefix` |

- **아이디 바꾸기에만 있는 것**: 지금 이름이 검토 계정이면 400 `review_account`(검토 계정 이름이 검토 요청과 사람 행동을 가르는 표식 — 감사 origin · 경보 · 시험 R-73) · 지금 이름이 공용 토큰 귀속이면 409 `shared_token_user`(3장) · 같은 이름이면 「바뀐 것 없음」 400(기존 관례).
- **순서**: 허용 키 → 사유 → 값 좁히기(형식) → 바뀐 것 있나 → 권한(`self_change` · `last_admin`) → **[5b]** 검토 계정 → 공용 토큰 → 이미 있음 → 검토 접두 → UPDATE(23505 는 `already_exists`). 권한 판단 **뒤**에 이름 사정을 본다 — 권한 없는 사람에게 이름 사정을 먼저 알려 주지 않는다.
- **감사**(기존 `user.update` 관례 그대로 — 5-A″ 이름 칸): action `user.update` · `detail.changed_fields = ["username"]` · `before`/`after` 는 권한 칸만(전과 같음) · `sessions_revoked` 0 · `reason_text`. **아이디의 값은 새것도 옛것도 detail 에 넣지 않는다** — 그 행의 `target_name` 이 바꾸기 **전** 아이디(행 target 규칙 그대로)이고, 새 아이디는 감사 어디에도 없다. 거부 행도 대상은 바꾸려는 계정(지금 이름)이고 **시도한 새 이름은 남기지 않는다**(새 아이디 후보·오타가 기록에 쌓이면 목적이 샌다). 누구든 계정 번호 `target_id` 로 지금 행을 찾는다. 문장 글자는 「이름·아이디를 바꿨습니다」로 넓혔다(이름만 바꾼 행도 같은 글자).
- **세션**: 끊지 않는다 — 권한이 바뀐 것이 아니다(이름 칸과 같다). 세션·개인 토큰·2단계 비밀·잠금 칸은 모두 계정 **번호**에 묶여 있다(7장 실측).

## 3. 공용 토큰 가드 (닫힌 실패, 409)

`.env` 의 공용 프로그램 토큰(`API_TOKEN`)은 귀속 계정을 **아이디 글자**(`API_TOKEN_USER`)로 찾는다(`src/Auth.php` `requireApiToken` ③ — `SQL_LOAD_USER … WHERE username`). 그래서 귀속 계정의 아이디를 바꾸는 순간 공용 토큰은 503 「API 토큰 귀속 계정이 올바르지 않습니다」로 끊긴다(임시 인스턴스 실측). 운영에서는 공용 토큰이 **켜져 있고**(48자) 귀속이 **운영의 유일한 사람 관리자**다 — 이번에 아이디를 바꿀 바로 그 계정이다(값은 찍지 않고 역할·접두만 대조).
