단추DESIGN 2.1

무게가 다른 다섯 변형. 한 화면에 검정(주요)은 하나, 되돌릴 수 없는 것은 빨간 글자, 표 안은 아이콘.

변형 — 왼쪽부터 무게 순. 한 화면에 검정은 하나

.btn 주요 동작. 사용자가 이 화면에 온 목적 하나.
.btn--quiet outline. 그 다음 동작들.
ghost 도움말처럼 없어도 흐름이 끊기지 않는 것.
.btn--danger 되돌릴 수 없는 것. 뒤에 사유·확인이 따른다.
disabled 50% 반투명. 이유는 툴팁에.

크기 — 표 안·카드 머리는 작은 것

.btn--quiet
.btn--small — 표 안 글자 단추
.btn--danger.btn--small
.btn--block 독립 화면의 칸 하나~셋짜리 폼(로그인·재인증)

아이콘 단추 — 표 행 안. 색은 뜻으로만: 받기 파랑 · 삭제 빨강 · 나머지 회색. 올리면 툴팁

순서 고정: 보기 → 받기 → 고치기 → 공유 → 이동 → 삭제. aria-label 이 툴팁 글이다 — 마우스를 올려 보세요.
막힌 동작은 비활성 + 이유를 라벨에.

위계 실제 예 — 화면 머리 오른쪽. ghost → outline → 검정 순서

하지 말 것. 검정 두 개 나란히 · 파란 단추 · 「확인」「OK」(동사형 한글로) · 링크를 단추 대신(<a>는 이동, <button>은 동작).

새 화면 체크리스트DESIGN 6장

  • 화면 머리에 검정 단추가 하나이고 ghost → outline → 검정 순서다

  • 되돌릴 수 없는 동작은 .btn--danger 이고 사유·확인이 따른다
  • 새 배지는 색 뜻에 맞고 새 색값을 만들지 않았다
  • 나란히 놓인 패널은 .grid-2 다
  • 모달은 여섯 폭 중 하나다
  • 인라인 style · script · 외부 URL 이 없다
  • 화면에 역할 비교·필터 로직이 없다 — 보이고 안 보이고는 /api/me 의 can_* 로만
