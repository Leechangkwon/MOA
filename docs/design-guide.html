고대비DESIGN 2.16

「내 계정」 → 「화면」 → 「고대비 화면」을 켠 사람에게만 서버가 <html data-contrast="high"> 를 그린다. 토큰 값만 바뀐다 — 이름·클래스·마크업은 그대로, 해/달(밝게·어둡게)과는 독립인 두 축.

고대비 켬 — 아래 두 틀은 같은 app.css · community.css 를 입히고 틀의 <html> 에 속성만 붙였다(왼쪽 밝게 · 오른쪽 어둡게)

확인하는 법. 이 견본 전체를 고대비로 보려면 개발자도구에서 이 문서의 <html> 에 data-contrast="high" 를 붙인다(해/달 단추와 함께 눌러 두 축을 모두 본다). 대비는 눈이 아니라 tests/lib/contrast.py 가 계산한다 — 글자 ≥ 4.5 · 선·고리 ≥ 3. OS 의 강제 고대비(forced-colors)는 다루지 않는다.

새 화면 체크리스트DESIGN 6장

구현 지시서와 검토 보고에 그대로 붙인다.

  • 화면 머리에 검정 단추가 하나이고 ghost → outline → 검정 순서다
  • 표는 .table-wrap 안에 있고 긴 값 열에 nth-child 폭 규칙을 적었다
  • 아이콘 단추는 makeIconButton 으로 만들어 aria-label 이 있다
  • 되돌릴 수 없는 동작은 .btn--danger 이고 사유·확인이 따른다
  • 새 배지는 색 뜻에 맞고 새 색값을 만들지 않았다
  • 나란히 놓인 패널은 .grid-2 다
  • 모달은 여섯 폭 중 하나다
  • 인라인 style · script · 외부 URL 이 없다
  • 화면에 역할 비교·필터 로직이 없다 — 보이고 안 보이고는 /api/me 의 can_* 로만
  • ui_snapshot.sh 를 1440 · 1280 에서 돌려 결함·콘솔을 확인했다
  • 행 동작이 있는 표는 td.actions 에 동작 · 첫 칸에 이름 — 360·412 에서 쌓여 동작 단추가 화면 안이다
  • 브라우저 기본 창(alert · prompt · confirm) 0 — 값은 .modal--form, 확인은 openConfirm, 창 안이면 확인 줄
  • 쓰는 단추는 can_*(커뮤니티는 /api/me 의 can_community_write 도)로 숨긴다 — 손님 문맥으로 한 번 열어 본다
  • 창 바닥은 오른쪽 끝 주요 하나 · 그 왼쪽 「닫기」(테두리) · 본문 검정·제출 0 · 머리 ✕ · 「그만두기」 0 (2.7)
  • 화면 글자는 낱말 표의 말(받기 · 지우기 · 되살리기 · 등급 · 내 계정) · 고르개 글자에 영어 값 0 (5장)
  • 폰 폭에서 누르는 것의 누름 자리 44×44 이상 — 보이는 크기는 그대로 (4장)
  • 고대비 켬(data-contrast="high")에서도 네 폭 × 밝게·어둡게 넘침 0 · 콘솔 0 — 고대비 값은 토큰 블록 세 곳에만 (2.16)
