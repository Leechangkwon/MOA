# 모아 메신저 AI

## 사용 방법

1. 관리자 계정으로 `/tbox/users#member-ai-settings`를 연다.
2. Google AI Studio의 API 키 전체를 입력하고 ‘AI 대화 사용’을 ‘구성원에게 열기’로 저장한다.
3. `/tbox/messages`에서 ‘모아 AI’를 선택한다. 구성원은 각자 모아 계정으로 로그인하면 된다.

모델은 `gemini-3.5-flash`로 고정한다. 다른 모델로 자동 대체하지 않는다. 새 대화, 본인 대화 기록 선택, 이전 대화 불러오기, 답변 대기·오류 표시를 제공한다. tbox-buddy PC 설치와 별개인 웹 대화 기능이다.

## 여러 사람이 사용하는 방식

| 방식 | 적용 상태와 판단 |
| --- | --- |
| 서버 공용 키 + 사용자별 대화 | 구현. 브라우저에 키를 주지 않으며 모든 대화 조회·전송은 현재 로그인 사용자에게 묶인다. |
| 모아 전용 Google 프로젝트 | 사용량·비용을 New_ERP2와 구분하고 싶을 때 권장. 키를 생성할 프로젝트는 관리자가 선택한다. |
| 개인별 API 키·프로젝트 | 개인별 비용 부담이 필요할 때 확장 가능. 현재는 구현하지 않았다. 같은 프로젝트에 키만 여러 개 만들어도 프로젝트 한도가 늘지 않는다. |

Google API 키가 한 사람의 Google 계정에서 발급되었다는 사실이 앱 이용자 한 명만 쓸 수 있다는 뜻은 아니다. 서버 앱은 해당 프로젝트 자격으로 호출하고 모아가 사용자별 권한과 기록을 관리한다. 실제 호출 가능량과 요금은 Google 프로젝트 설정에 따른다. 기본 모아 제한은 사용자 40회/일, 전체 300회/일이며 관리자 화면에서 조정한다. 사용자 4회/분, 전체 12회/분, 동시 사용자별 1건·전체 2건 제한도 있다. 한도 초과 시 기다린 뒤 수동 재전송한다. 대기열과 자동 재시도는 없다.

일일 횟수는 한국 시간 자정에 초기화된다. 실패하거나 결과가 불확실한 요청도 집계한다. 이것은 금액 상한이 아니다. 같은 요청 UUID의 재전송은 기존 결과를 반환하며 Google을 다시 호출하지 않는다. 새 요청으로 다시 보내면 별도로 집계된다.

## 전송·저장 범위

- 사용자가 AI에게 입력한 질문과 같은 AI 대화의 최근 완료 기록만 Google로 전달한다. 최대 최근 10개 질문/답변, 합계 16,000자. 새 질문 최대 4,000자, 출력 최대 4,096토큰/20,000자.
- 사람끼리 나눈 메시지·사내 파일·커뮤니티 문서를 자동으로 읽거나 전달하지 않는다. 웹 검색·PC 제어·파일 편집 도구도 없다.
- Google 무료 서비스에는 민감·기밀·개인정보를 입력하지 않도록 화면에서 안내한다. 유료 프로젝트 사용 여부는 관리자가 Google에서 확인해야 한다.
- 키는 `/var/lib/tbox-v2/private-messenger-ai/gemini.key`에 저장한다. 디렉터리 0700, 파일 0600, 웹루트·업로드 트리 밖이며 원문 조회 API가 없다. 교체는 임시 파일과 rename을 사용한다. 키는 DB 백업에 포함되지 않는다.

## 구현과 확인 범위

`db/migrations/2026-10-02_moa_ai.sql`을 운영 DB에 적용했다. 추가 테이블 3개를 만들고 기존 업무 행은 수정하지 않았다. 소유자는 tbox_owner, 앱은 SELECT/INSERT/UPDATE, 백업은 SELECT를 가진다. 기본 사용 상태는 off이다.

변경 PHP 문법, JavaScript 구문, 보안 정적 검사(금지 패턴 0), diff 공백 검사를 통과했다. 초기 구현 시 키가 없었으나 이후 설정 메타데이터에서 키 파일 등록·사용 켜짐과 완료된 AI 대화 1건을 확인했다. 질문·답변 내용이나 키 값은 열지 않았다. 개발 에이전트가 직접 Google 호출을 실행한 것은 아니며 프로젝트 등급은 확인하지 않았다. 동시 사용자 실행 시험과 브라우저 수락 시험도 실행하지 않았다. 키를 등록하면 실제 대화에서 확인할 수 있다.

키 입력 오류 수정: 첫 구현이 영숫자·밑줄·붙임표 20~256자로 제한하여 새 authorization key의 점(`.`)을 거부했다. 서버·전송부·입력칸을 공백/제어 문자가 없는 출력 가능한 ASCII 20~4096자로 수정했다. 형식 검사와 실제 Google 인증 오류는 다른 문구로 표시한다. 키의 유효성은 실제 Google 호출에서 판단한다.

참조한 New_ERP2 main은 `758ec21fccf545fb36d14ed2dcbfce1d4f4ec076`. 트리·설정·Gemini 커밋 검색에서 기존 연동 위치를 찾지 못했고, 사용자는 공식 API 방식으로 진행하기로 결정했다. 해당 저장소는 변경하지 않았다.

## 직원 간 대화의 AI 도구 (추가)

- 직원 선택 → 작성란 위 `AI 도구` → 문장 다듬기/맞춤법/번역/이미지 만들기 → 나만 보는 결과 확인 → 작성란에 넣기 또는 첨부 → 사용자가 전송. 문장을 다듬은 뒤 원문으로 되돌릴 수 있다.
- 받은 메시지의 `번역`은 선택한 메시지 한 건만 서버에서 참여자 범위를 확인해 읽는다. 번역 언어는 한국어·영어·일본어·중국어·베트남어·스페인어다. 대화 전체를 자동 전달하지 않는다.
- 도구 원문/결과는 `member_ai_assists`에 요청자별로 보관한다. 최근 결과 8건을 해당 상대별로 다시 볼 수 있다. 다른 상대를 열면 작성 중 문장과 첨부를 각각 복원한다.
- 나만의 AI 대화와 도구는 공통 분당/일일/동시 요청 한도를 사용한다. 동일 사용자+요청 UUID는 같은 결과를 돌려준다. 전송 오류 뒤 상태 조회만 자동 수행하고 새 생성 요청은 자동 재시도하지 않는다.
- 이미지 모델은 `gemini-3.1-flash-lite-image`, 공식 Interactions API, `store:false`, 기본 1K, 비율 1:1/16:9/9:16. 관리자의 이미지 사용 켜기와 Google 유료 프로젝트가 필요하다. 기본 off, 개인 3회/일·사이트 20회/일(전체 요청 수에도 포함), 실패/불확실 요청 포함. PNG/JPEG만 저장·미리보기하며 응답 12MiB/디코딩 6MiB/4M 픽셀/사이트 이미지 512MiB 보관 상한을 둔다. 자동 정리 작업은 추가하지 않았으므로 보관 상한 도달 시 관리가 필요하다.
- 이미지는 기존 Storage의 난수 이름·파일 권한·SHA-256 확인·인증된 스트림으로 제공한다. 보내기 전에는 생성자만, 보낸 뒤에는 메시지 참여자만 볼 수 있다. 같은 이미지의 중복 전송은 첨부 UUID로 방지한다. 일반 파일 목록·공유 링크에는 자동 등록하지 않는다.
- `2026-10-02_moa_assists.sql` 운영 적용: 설정 컬럼 3개, 도구 테이블, 기존 메시지의 nullable 첨부 참조와 인덱스. 기존 메시지 본문/계정/파일 변경 없음.
- API 등록 입력칸은 상단 정렬·44px 높이, 저장 버튼은 별도 행. 보조 문구 길이가 다른 입력칸의 위치를 밀지 않도록 수정했다.
- PHP/JS 문법, 보안 정적 검사, diff 공백 검사 완료. 실제 도구 생성/번역/이미지/권한·경쟁 상태와 브라우저 화면은 실행 검증하지 않았다. 이미지 사용은 off로 유지했다.

## GPT와 개인 구독

일반 OpenAI GPT API는 사용량 과금이며 공용 무료 API를 전제로 추가하지 않았다. 대신 AI 도구 창에 `요청문 복사 → ChatGPT 열기`를 제공한다. 이는 외부 ChatGPT에서 사용자가 직접 붙여 넣는 흐름이며 OAuth 연결이나 결과 자동 회수가 아니다.

2026-10-02 공식 문서에는 Sign in with ChatGPT의 개인 요금제 사용 흐름이 존재한다. 공개 문서 대상은 로컬·오픈소스 앱이며 유료/원격 호스팅 앱은 별도 신청 안내가 있다. 사용자는 tbox-buddy 로컬 세션에서 작업하기로 했다. 구현 지시서는 `docs/tbox-buddy-chatgpt-prompt.txt`. 개인 토큰은 PC에만 보관하고 API 모델 목록/Responses SSE/실제 granted scope를 사용하는 구조다. 현재 이 OAuth 경로의 이미지 생성 도구는 미지원이다. 로컬 구현·로그인·웹과의 자동 연결을 완료했다고 주장하지 않는다.

### GPT 무료 API 설명 보완 (2026-10-02)

일반 GPT API의 사용량 과금 외에, 자격을 갖춘 조직이 API 입력·출력 데이터 공유에 동의하면 일일 무료 토큰을 받는 공식 프로그램이 있다. 앞선 답변은 이 조건부 혜택을 설명하지 않았다. 적용 대상 여부는 OpenAI 데이터 공유 설정의 무료 일일 사용 자격 안내로 확인한다. 양수 계정 잔액이 필요하며, 대상 모델 그룹 합산 한도를 넘기는 요청은 과금될 수 있다. 사용자 조직의 자격·신청 여부는 확인하지 않았고 데이터 공유 설정도 변경하지 않았다. 모아의 사내·개인정보 메시지에 적용하기 전에 공유 범위와 권한을 확인해야 한다.
