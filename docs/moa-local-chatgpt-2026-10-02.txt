6. 후속 자동 전달 설계 — 제안이며 현재 미구현

구현 지시서와 정확한 요청/응답 계약은 docs/tbox-buddy-bridge-prompt.txt에 있다.
핵심: 별도 127.0.0.1:43821 리스너(제안 포트), 명시적 페어링,
OpenAI와 독립된 단기 자격, 엄격한 Host/Origin, 요청 만료/nonce/ID 중복 차단,
매 요청 PC 확인, 완료 SSE만 최종 결과, 웹 미리보기/적용/전송을 각각 분리.
포트 사용 여부는 Windows에서 확인해야 한다. OAuth callback은 재사용하지 않는다.

웹 선행 조건:
현재 src/bootstrap.php는 default-src 'self'이며 별도 connect-src가 없다.
현재 CSP는 loopback fetch를 허용하지 않는다. 후속 웹 세션에서 메신저에 한정한
정확한 포트의 connect-src 예외를 검토/시험해야 한다. 이번에는 CSP를 완화하지 않았다.
추가로 HTTPS→loopback mixed content, CORS, Local Network Access 사용자 권한과
기업 브라우저 정책이 모두 충족되어야 한다. CORS만 맞췄다고 성공으로 표시하지 않는다.
참고: https://developer.chrome.com/blog/local-network-access
https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Local_network_access
Chrome 문서의 LNA는 예전 PNA만으로 설명할 수 없다. Windows Chrome/Edge/Firefox의
실제 버전·권한 허용/거부/철회·기업 정책을 검증하고 지원하지 않으면 수동 흐름을 제공한다.
브라우저 보안 옵션을 끄도록 요구하거나 서버 공용 프록시로 우회하지 않는다.

7. Git/운영 반영 기록

별도 배포 기록 파일: docs/moa-local-deployment-2026-10-02.json.

포함하게 되므로, 작업 전 사본/해시와 이번 파일별 기록으로 변경을 보존한다.
DB migration, 운영 데이터 변경, 서비스 설정 변경, Windows 브랜치 수정은 없다.

검증용 PHP 서버를 종료하고 임시 .env/합성 세션 fixture를 제거했다.
이번에 새로 만든 tbox_moa_local_tqa7soex DB만 삭제했다. 운영 DB는 변경하지 않았다.
