# 모아 — 디자인, 초대 가입, 비서 안내, 메신저

2026-10-02 운영 반영. 사용자 요청으로 브랜드를 모아로 바꾸고 커뮤니티 중심 홈을 구성했다. 기존 계정·파일·게시판 데이터와 작업 중이던 변경을 보존했다.

## 사용 방법

- 홈: https://changkwon.mso.so/
- 관리자 → 계정 관리(`/tbox/users`) → **초대 링크 만들기**. 초대 이름·소속 팀·가능 인원(1~100)·기간(1~30일)을 정하고 발급된 링크를 전달한다. 원문은 한 번만 표시한다. 목록에서 회수할 수 있다.
- 초대받은 사람: 링크 → 이름·아이디·비밀번호 → OTP QR 등록 → tbox-buddy 설치/토큰 안내 → 커뮤니티 또는 메신저.
- 기존 사용자도 `/tbox/welcome`에서 OTP·비서 연결을 설정할 수 있다.
- 메신저: `/tbox/messages`. 구성원 검색, 1:1 메시지, 읽음과 미읽음, 이전 대화. 새 메시지는 열린 탭에서 8초 간격으로 확인한다.
- 관리자 계정 관리 → **tbox-buddy 설치 파일 연결**에 실제 HTTPS 배포 URL을 저장하면 시작 안내의 다운로드 버튼이 활성화된다.

## 현재 한계

실제 tbox-buddy 설치 파일/주소가 제공되지 않아 운영 다운로드는 ‘배포 준비 중’이다. 이미 설치된 비서에는 기능별 개인 토큰을 발급해 연결할 수 있다. PC에서의 설치·토큰 저장·비서 연결 성공 자체는 시험하지 않았다. 웹 메신저이며 단체방·첨부·푸시와 비서 앱 내부 메신저 연동은 포함하지 않는다.

최신 뉴스나 사용자 활동을 가짜로 채우지 않았다. 공개 홈 읽을거리는 편집 콘텐츠, 로그인 후 소식은 실제 권한 필터를 거친 게시판 데이터다. 사진은 자체 호스팅하며 출처와 해시는 `public/assets/moa/sources.json`에 있다.

## 반영 구조

추가 전용 테이블 4개(`member_invites`, `member_rate_limits`, `member_settings`, `member_messages`)와 `users.invited_account`를 `db/migrations/2026-10-02_moa.sql`로 원자적으로 적용했다. 새 설치의 schema/grants도 갱신했다. Auth의 기존 계정 MFA 정책은 보존하고 초대 가입자만 OTP를 필수로 한다. 기존 X-API-Token 허용 라우트를 넓히지 않았다. 초대·메신저는 브라우저 세션용이다.

코드/스키마 사본은 `/tmp/moa-backup/`. 운영 DB 백업은 변경 전 스키마만 보관했으며 이번 마이그레이션은 기존 업무 행을 변경하지 않는 추가 작업이다. 운영 데이터 되돌리기·삭제·재시딩은 실행하지 않았다. 저장소에는 이미 다른 기능의 미커밋 변경이 많아 일괄 커밋·발행하지 않았다.

### 메신저 본인·상대 표시 수정

사용자가 pkdkak1로 로그인했는데 화면이 employee01끼리 대화하는 것처럼 보인다고 지적했다. 기존 화면에는 본인 프로필과 말풍선의 발신자 표기가 없었다. 본문을 읽지 않고 발신·수신 계정만 확인한 기존 메시지는 pkdkak1 → employee01로 저장되어 있었다. 메신저 왼쪽에 서버 세션 기반 ‘내 계정’ 아이디, 대화 상단에 ‘상대 님과의 대화’, 말풍선에 ‘나 · 아이디’/‘상대 · 아이디’를 표시했다. PHP/JS 구문 통과. 외부 요청 없는 브라우저 fixture에서 390/1440px 본인·상대·발신자·가로 넘침·JS 오류 12/12 통과. 계정이나 기존 메시지는 수정하지 않았다.

### 공간 로고·사용 안내 개선

- 자료실: 문서가 든 폴더 아이콘, 파일 보관·검색·공유 안내와 실제 업로드/검색/목록 바로가기.
- 커뮤니티: 겹친 말풍선 아이콘, 소식·질문 게시판/문서 작성/오늘 할 일로 진입. 개인 문서 목록을 별도 ‘내 문서’ 영역으로 분리.
- 로고 클릭은 해당 공간 홈으로 이동하며, 계정·공간 메뉴는 별도 단추로 유지. 홈·사이드바·앱 메뉴에서 동일한 이름과 아이콘 사용.
- 회의 기록, 자료와 설명 전달, 인수인계의 실제 활용 순서를 접을 수 있는 안내로 제공. 도움말도 같은 목적 중심으로 보완.
- PHP/JS/JSON 문법 및 보안 정적 검사 확인. 브라우저 사용성 시험은 실행하지 않음. 이번 변경은 DB를 변경하지 않음.
