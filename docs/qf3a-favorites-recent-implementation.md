### 12.5 시간 · 자원 (지시 「PHP 시간 한도와 맞는지」)

- 500MB(100MB × 5) 실측(php -S · 페이지 캐시 따뜻함): 머리까지 18.7초 = sha256 500MB + 담기 500MB · 끝까지 21.8초 · 메모리 그대로(스트리밍 — `readfile`·libzip).
- nginx `fastcgi_read_timeout 60s` 는 **첫 바이트까지** — 18.7초로 안. FPM `request_terminate_timeout 90s` 는 PHP 가 응답을 다 넘길 때까지 —
  운영은 nginx 가 응답을 `fastcgi_max_temp_file_size`(기본 1024m) 안에서 임시 파일로 받아 두므로 PHP 쪽은 ≈ 만들기 + 로컬 복사(느린 손님과 무관).
- 겹치면: 슬롯 둘이 동시에 500MB 면 디스크를 나눠 써서 머리까지 두 배 가까이(추정 ≈ 40초) — 60초 안이지만 여유가 좁다(**미실측**). 운영 디스크가 차갑거나 바쁘면
  더 느릴 수 있다. 줄이는 길: 한도를 낮춘다 · 슬롯을 하나로 · (다음 라운드) 담기 전 sha256 을 담으면서 재기(두 번 읽기 → 한 번) — C-U4.
- 워커가 90초에 죽으면 shutdown 함수도 안 돈다 → `zip-*` 가 남고 다음 zip 요청이 10분 뒤 치운다. 잠금은 프로세스가 죽으면 커널이 푼다.
