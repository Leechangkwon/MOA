## 1. 한 줄 요약
사내 구성원이 **계정 하나**로 로그인해, 첫 화면 **앱 런처**에서 기능을 골라 들어가는 사이트. 지금 모듈은 둘 — **t-box**(파일 공유, 완성·운영 중)와 **커뮤니티**(노션처럼 블록으로 쓰는 개인 업무 공간 · 게시판 · 인계, 기획 중). 뒤에 사내 도구가 타일로 늘어난다.

## 2. 배경과 결정 이력
- t-box 는 보안 실습 과제(5대 취약점 없는 파일 공유)로 완성돼 `changkwon.mso.so` 에서 운영 중이다.
- 강사 과제 「커뮤니티를 만들라」(2026-09-21). 처음엔 별도 앱(`/var/www/community`)으로 1·2단계 게시판을 만들었으나, 사용자 결정(2026-09-22): ① 기존 게시판 코드는 「만들어진 것 없이 만들어진 상태」— 참고용 뼈대 ② **기획을 끝낸 뒤 그 결정대로 처음부터** ③ 강사 지시는 「따로 만들라」가 아니었으므로 **한 사이트로 합친다** ④ 이름은 **Qaredi** ⑤ 입구는 구글식 **앱 런처**.
- 판단 기준(사용자 지적): 「노션에 있나」가 아니라 **「우리가 쓰기에 더 좋은가」**. 필요·불필요는 사용자가 정하고 Fable 은 보조한다.

## 4. 런처 (Q:F-1) — 설계 `docs/launcher/ARCHITECTURE.md`
- **로그인 전에도 보이는** 첫 화면(Q-B). 타일 = `config/apps.json`(이름·설명·경로·아이콘·순서·상태), 읽기는 `src/Apps.php` 한 곳. 타일을 누르면 그 앱(로그인이 필요하면 그 앱의 로그인 화면). 미로그인 런처는 개인 데이터를 내려 주지 않는다. 디자인 제어 design.js 한 개, 서버 쿠키 발행 0. 로그인한 런처는 start.js를 추가해 기존 최근·즐겨찾기 API의 허용된 항목을 표시한다. 로그인돼 있으면 사용자 칩(표시 이름·역할)이 더해진다. 아직 없는 앱(커뮤니티)은 「준비 중」 배지, 링크 없음.
- 로그아웃 단추는 **v1 런처에 없다**(정정 2026-09-22): CSRF 헤더가 필요해 스크립트 없이는 안 되고, 로그아웃은 각 앱 안에 있다. 뒤에 넣으려면 「스크립트 0」 원칙과 저울질한다.
- 각 모듈 셸 머리 오른쬬에 그리드 단추(⋮⋮⋮) → `<details>` 팝업(같은 목록 + 「Qaredi 홈」). 스크립트 없이 열린다.
- 주소 규칙: `/` 런처 · `/tbox/…` t-box · `/community/…` 커뮤니티. **옛 t-box 주소는 308** 로 새 주소로(메서드·본문 보존, Q-F). 쿠키 `path=/`·CSP·CSRF 무변경.
- 런처에는 알림 요약(커뮤니티 미읽음 n·t-box 검사 중 파일 n)을 뒤에 더할 수 있다(선택).

## 5. 커뮤니티 모듈 — 확정된 것 (상세는 `community/PRD.md` v0.3)
- 개인 공간(사용자마다) → 페이지 트리 → **블록 JSON 본문**(HTML 0). 꾸밈은 노션 수준 이상(색·배경·크기·정렬·관리자 팔레트). 에디터 엔진 ProseMirror.
- 공개 범위 비공개·팀·사내·게시(자식 ≤ 부모). 비공개는 소유자 + Admin(열람은 감사 기록, ⑦ 결정). 게시 = 원본을 게시판에 걸기.
- 기록은 지울 수 없다: 버전 이력·체크 완료자·인계·읽음.
- 게시판 종류·댓글(블록 앵커·인용)·멘션·알림·역참조·t-box 첨부·데이터베이스·인계·휴지통·읽음 확인·템플릿·임베드 허용 목록 — 항목별 결정 N-1~N-11 은 `community/notion-structure-and-design.md` 9장.

## 2026-10-02 사용자 변경 요청 — 모아

이전 이름 고정·업무 런처 우선 지침보다 이번 사용자 요청을 우선한다. 화면 브랜드는 **모아**, 파일 모듈은 **자료실**, 기술 경로(`/tbox`, `/community`)는 기존 연결과 호환된다. 첫 화면은 풍경 사진·에디터 읽을거리·로그인 사용자에게만 보이는 실제 게시판 글을 중심으로 구성한다. 가짜 최신 뉴스·활동 수·회원 글을 만들지 않는다.

가입 방식은 사용자가 **초대 링크를 받은 사람만 가입**으로 확정했다. 관리자는 만료일·인원·팀을 정한 링크를 발급·회수하고, 초대받은 사람은 아이디·이름·비밀번호를 직접 정한다. 초대로 가입한 계정은 일반 구성원(Employee)이고 OTP 등록 전 업무 기능이 차단된다. OTP 이후 tbox-buddy 설치·개인 토큰 설정 안내로 이어진다. 별도 요청한 메신저는 구성원 간 웹 1:1 메시지, 읽음·읽지 않음, 이전 대화를 지원한다.

실제 tbox-buddy 설치 파일은 서버에 제공되지 않았다. 관리자 계정 관리에서 HTTPS 배포 주소를 등록하면 가입 안내에 다운로드가 표시된다. PC 프로그램 자동 설치·PC 내부 토큰 저장 완료를 웹에서 가장하지 않는다. 검증과 운영 결과: `tbox-v2/docs/moa-release-2026-10-02.md`.
