# 서버 외부 문서의 Git 전달 사본

이 폴더는 2026-10-03 `/var/www/qaredi`의 Git2 밖 문서를 명시적으로 복사한 것이다. 원본 경로·기준 커밋·최초 SHA-256은 `snapshot.json`에 있다. 비밀 설정이나 운영 데이터는 포함하지 않는다.

휴가 중에는 이 저장소 안의 사본을 고쳐 변경을 전달한다. `snapshot.json`의 최초 해시는 촬영 시점의 증거이므로 문서 수정 때 현재 해시인 것처럼 바꾸지 않는다. 서버 복귀 시 원본과 변경을 비교·병합한 후 다시 사본을 갱신한다. 서로 다른 원본을 통째로 덮어쓰지 않는다.

`site-rules.md`는 당시 공통 지침의 보관 사본이다. 모델 이름과 담당 분담 같은 과거 환경 설명보다 현재 사용자·실행 환경 지침이 우선한다. 지금 작업 방법은 저장소 루트 `AGENTS.md`와 `docs/CLOUD-HANDOFF.md`를 따른다. 오래된 문서의 ‘대기’ 문구는 해당 시점 기록이며 최신 배포 상태로 해석하지 않는다.
