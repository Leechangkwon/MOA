## 보충
- 기존 `#upload-folder`·`#fetch-folder` <select> 는 제거하고 `<span id="upload-where">`·`<span id="fetch-where">` 같은 읽기 전용 글자로 바꾼다. 경로 글자는 서버가 내려 준 `folder.breadcrumb`(GET /api/files 응답)의 이름을 「 › 」 로 이어 만든다 — textContent.
- 서버 계약은 그대로다: 파일 하나 = 요청 하나, `folder` 필드 = state.folder(0 = 루트면 필드 생략 또는 0, 지금 코드가 보내는 방식 유지).
- 「검토 계정·표식」 규칙(CLAUDE.md 3장): 회귀는 qa_ 계정 + `-A "tbox-review/$(date +%F)"`. 자격증명 파일은 cat 금지, 필요한 필드만 awk(seed-accounts: 1=계정 2=역할 3=비밀번호 / qa-totp: 1=계정 2=비밀, TOTP 코드는 `sudo php scripts/totp_code.php <비밀>`). 비밀 값은 출력·보고에 절대 넣지 않는다.
- 이 서버는 **작업 트리가 곧 서비스**다. 파일을 반쯤 쓴 상태가 노출되지 않게 한 파일은 한 번의 쓰기로 바꾸고, 저장 직후 `php -l`/`node --check` 를 같은 명령에서 돌린다.
