### 2.2 최종적으로 통하는 명령 (서버 `changkwon@eric` 기준)

```bash
# 상태 확인 (로그인 없음)
curl -s -w ' [%{http_code}]\n' https://changkwon.mso.so/api/health

# 토큰을 변수에 (값은 화면에 안 찍힘 · 토큰 회전 뒤에는 다시 실행)
export API_TOKEN=$(grep '^API_TOKEN=' /var/www/tbox-v2/.env | cut -d= -f2-)

# 업로드 (level 을 빼면 public) → 201 {"id","name","level"}
curl -s -w '\n[%{http_code}]\n' -H "X-API-Token: $API_TOKEN" \
  -F 'file=@/tmp/api-test.txt' -F 'description=curl 테스트' \
  https://changkwon.mso.so/api/upload

# 검색 → 200 [{"id","name","level","size","uploaded_at"}]
curl -s -w '\n[%{http_code}]\n' -H "X-API-Token: $API_TOKEN" \
  'https://changkwon.mso.so/api/files?q=api-test&limit=8'

# 다운로드 — 검색 결과의 id 를 꺾쇠 없이 → 200, 현재 폴더에 원래 이름으로 저장
curl -s -OJ -w '[%{http_code}]\n' -H "X-API-Token: $API_TOKEN" \
  https://changkwon.mso.so/api/files/f30f796c-57ff-4006-9298-4084c8ece953/download
```

`API.md` 를 PC 로 옮기는 명령은 **PC 의 PowerShell** 에서 실행한다(서버 터미널이 아님). 서버 주소는 서버에서 `echo $SSH_CONNECTION | awk '{print $3}'` 로 확인한다.


### 3.1 「2차 비밀번호 → 토큰 전환」 87분(19:13→20:40)의 분해

- **폐기·재작업 33분**(19:35→20:07): 강사 2차 프롬프트가 19:56 에 도착했는데, 그 43분 전(19:13)에 그 프롬프트의 curl 만 먼저 실행됐다. 프롬프트 본문 없이 curl 의 모양(`X-API-Token`)만 보고 「제대로 된」 토큰 설계(v1)를 추측해 만들었고, 실제 스펙(`.env` 정적 토큰 하나)이 오자 전부 되돌렸다. **프롬프트를 먼저 붙이고 명령은 나중에 실행했으면 이 33분은 없었다.**
- **방향 탐색 16분**: 「OTP 를 없애 달라」는 요청이 PRD F-16 ③과 충돌해 선택지를 묻고, 다시 「보안 우회」를 시험 모드로 해석하고, 그다음 강사 의도를 두 번 물었다. 이 과정에서 Fable 이 **로그인은 8시간에 한 번이면 된다**는 사실을 19:22 에서야 알렸다(19:14 첫 답에 넣을 수 있었다 — 세션 기록에 「앞선 대화에서 이 점을 안 알려 드려서」라고 스스로 적음).
- **구현 20분 + 검토 9분 + 문서 15분 = 44분**은 v2 저장소의 규칙(CLAUDE.md: 문서 우선 → 지시서 → Opus 구현 → Fable 검토 → 시험 → STAGES/SECURITY 기록 → 커밋 → 발행)을 지키는 데 드는 **고정 비용**이다. 같은 요청을 v1 샘플(`/var/www/html`, 규칙 없음)에 한 세션이 바로 짰으면 5~10분짜리다. 다만 이 검토가 실제 결함 1건(.exe 이유 문구 누락)을 잡았고, F-50 에서는 Opus 가 지시서 결함(웹 로그인 401)을 잡았다. 시간을 산 것은 맞다.

## 4. 다음 실습에서 이렇게 하면

1. **강사 프롬프트는 본문부터 붙인다. 명령은 그 뒤에.** 오늘의 폐기·재작업 33분은 curl 이 본문보다 먼저 실행돼 생겼다. 2·3차처럼 여러 장이 예고되면 한 번에 붙이는 편이 설계 충돌을 막는다.
2. **실습은 대상 저장소를 먼저 정한다.** 강사 스펙이 v1(`/var/www/html`)이면 그쪽에 적용하는 것이 가장 빠르다. v2 에 적용하려면 「실습 모드」(문서 갱신·발행은 뒤로 미루고 구현·검토만)를 CLAUDE.md 예외로 정해 두면 API 당 10분 안으로 줄 수 있다. 어느 쪽이든 **사용자 결정**이다.
3. **자리표시자는 값으로 바꿔서 입력한다.** `<아이디>`·`<id>`·`서버주소` 는 전부 자리표시자다. 꺾쇠·따옴표 없이 실제 값을 넣는다. 셸에서 `<` 는 입력 리다이렉트, `$( )` 는 명령 실행이다.
4. **명령이 서버용인지 PC용인지 프롬프트로 구분한다.** `changkwon@eric:` 은 서버, `PS C:\Users\user>` 는 PC. `scp` 로 서버 파일을 PC 로 받는 명령은 PC 에서 친다. PC 의 `$(whoami)` 는 `user` 라 도메인은 `changkwon.mso.so` 로 고정한다.
5. **세션은 tmux 안에서 시작한다.** `tmux new -s tbox` → `cd /var && claude`. 끊기면 `tmux attach -t tbox`. Remote Control 은 조직 정책으로 비활성.
6. **OTP 는 로그인 때 한 번이다.** 토큰 API 가 없어도 `curl -c jar` 로 저장한 쿠키를 8시간 재사용하면 프로그램 시험은 된다. 토큰 API 를 만드는 것은 별개의 과제로 본다.
7. **`API.md` 갱신 = PC 로 `scp` 한 번.** 로컬 Claude 가 새 장을 읽어야 앱을 고칠 수 있다.
8. **토큰 회전은 귀속 계정을 바꿀 때만.** 회전 뒤에는 `export API_TOKEN=…` 을 다시 실행한다.
9. **시험 전 `df -h /`.** 여유 1GB 미만이면 시작하지 않는다(R-80, `tests/health.sh` 부터 적용).
