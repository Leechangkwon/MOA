# 화면 문구 정리 — 삭제 대기 목록 (사용자 승인 뒤 실행)

작성 2026-09-14 (Fable). 사용자 지시: 「라이브 서비스라면 2단계 인증 필요 여부, 삭제 주기, 권한이 있는 파일만·기록이 남는 방식, 사내망·VPN 같은 설명은 필요 없다. 관련 내용을 전체 재확인해 삭제 대기 리스트를 만들라. 승인하면 삭제한다.」

## 기준

| 판정 | 뜻 |
|---|---|
| **삭제** | 서비스가 「어떻게 지키는지」를 설명하는 문장(서버가 확인·감사 로그·세션·재인증 이유·트랜잭션·잠금 규칙·보존 기간·접속망) · 문서 번호(S-xx·R-xx·T-xx·AL-xx·F-xx·N단계·PRD·ARCH) · 과제 검토자를 향한 설득. 사용자가 일을 하는 데 필요 없다 |
| **축소** | 한 문장 안에 조작 안내와 설명이 섞여 있어 설명 부분만 지우고 남긴다. 「→」 뒤가 남길 문안 |
| **유지** | 조작 안내(무엇을 누르면 무엇이 됨) · 사용자가 알아야 하는 제약(형식·크기·사유 필수·되돌릴 수 없음·다시 볼 수 없음) · 빈 상태 문구 |

코드 주석(`<!-- -->`, `//`)과 시험·문서는 대상이 아니다(사용자에게 보이지 않는다). 위키는 별도 항목(§12)이다.

전체 209건을 훑어 **삭제 41 · 축소 22 · 유지(목록에 없음) 나머지**. 번호로 승인·제외를 말해 주면 그대로 실행한다. 「전부」도 된다.
