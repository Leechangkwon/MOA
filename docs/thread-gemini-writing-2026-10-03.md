# 스레드 사진을 참고하는 Gemini 글쓰기

`insta` 후속 구현이며 아직 이 클라우드에서 운영 배포하지 않았다. 기존 모아 Gemini 문장 도구와 스레드의 GPT 텍스트 모달이 서로 연결되지 않아, 스레드 사진을 참고하는 글쓰기가 빠져 있었다. 이 기능은 Codex/PC의 MCP 연결 없이 앱 서버에서 동작한다.

## 사용자 흐름

내 스레드의 **AI로 꾸미기 → 사진 선택 → 원하는 분위기·요청 입력 → Gemini로 글쓰기 → 초안 확인 → 기존 글에 추가하기 → 변경 저장하기**. 사진과 현재 메모를 기준으로 추가 단락을 만든다. 기본 요청은 ‘행복한 오늘의 기록을 따뜻하게 덧붙여 줘’다. 초안은 수정할 수 있으며 기존 사진과 글을 유지한다. 글·사진을 교체하는 기존 편집 흐름과 외부 ChatGPT 도구도 남아 있다.

버튼을 누를 때 Google로 보낼 범위를 안내한다. JPG/PNG/WebP 사진 최대 4장, 한 장 10MiB·합계 12MiB와 해당 글의 현재 메모·장소·날짜·이야기 모음·요청·분위기만 보낸다. 영상/GIF·과거 원본·다른 게시물·회원 대화는 자동으로 전송하지 않는다. 사진을 선택하지 않으면 메모만 참고한다. 생성한 글은 자동 게시하지 않는다.

## 기존 서버 설정 재사용

- `/tbox/users#member-ai-settings`에서 관리하는 모아 Gemini 키·활성화 설정과 `gemini-3.5-flash` 모델을 그대로 사용한다. 문서 AI의 별도 키나 OpenAI 키를 요구하지 않는다. 새 DB migration은 없다.
- `MemberAi::send`에 서버 내부의 사진 요청 준비 콜백만 추가했다. 기존 일반 대화 API는 이 콜백을 받을 수 없고 기존 동작을 유지한다. 사진 초안마다 본인 소유의 독립된 AI 대화와 요청 장부를 사용한다.
- 요청 요약·입력 지문·생성된 답변이 본인의 모아 AI 기록에 저장된다. 원본 이미지 바이트와 전체 게시물을 장부 prompt에 복사하지 않는다. 이 결과는 게시글과 별도인 AI 기록이므로 게시글 삭제만으로 AI 기록까지 삭제되는 것은 아니다.
- 기존 사용자/전체 일일·분당·동시 한도에 포함된다. 같은 요청 UUID·같은 참조 내용의 재시도는 기존 결과를 반환한다. 요청을 바꾸거나 완료 후 다시 생성하면 새 요청으로 집계한다. 자동 생성 재시도는 없다.

## 접근과 전송

기존 세션·CSRF·community.write 및 모아 메신저 자격을 적용한다. 역할 보기 모드는 허용하지 않는다. 현재 글 소유자와 revision, 선택한 현재 첨부 ID·소유자·게시물 귀속을 검사한다. 서버의 UUID 경로만 읽고 symlink·길이·SHA-256·이미지 MIME/해상도를 다시 확인한다. 전송 직전과 결과 반환 전에 계정·글의 상태를 재확인한다. 이미 바뀐 글은 새로 열어 요청해야 한다.

`Fetch::geminiDescribe`는 기존 고정 Google HTTPS 모델 주소·공인 IP 검사/IP 고정·TLS·리다이렉트 금지·55초 시간/응답 상한을 재사용한다. 이 경로의 요청 본문만 최대 17MiB다(사진 총량 12MiB의 base64와 메모 포함). 기존 텍스트·이미지 생성 경로의 180,000바이트 제한은 그대로다. 키·사진·본문·공급자 오류 원문은 감사/오류 로그에 넣지 않는다.

## 검증과 서버 인계

클라우드에서 실제 Chromium+합성 HTTP로 Gemini 8개, 스레드 12개, 사진 첨부 9개, 메신저 9개 시나리오를 통과했다. 390px 화면을 확인했다. 추가 초안의 자동 게시 방지, 원문/사진 보존, 사진 수 제한, 미설정 표시, 재시도 요청 ID, 다른 글을 연 뒤 늦게 온 응답 무시를 포함한다. 실제 Google 호출은 아니다.

PHP/PostgreSQL/nginx가 없으므로 PHP 실행·실제 DB 권한·공급자·서버 공통 회귀·실물 휴대폰은 아직 미검증이다. 다음을 서버의 기존 격리 검증 사본에서 실행한 후 배포한다.

1. `bash tests/community/memories_check.sh`: 새 PHP 바이너리/입력 단위 시험, 실제 PHP 템플릿, 공식 자산 버전/위키 및 브라우저 검사 포함. 설치된 Chromium을 쓰면 `CHROMIUM_EXECUTABLE`을 지정한다.
2. `python3 tests/community/memories_harness.py --suite memories_http.py --output /tmp/qaredi-gemini-http`: 기존 격리 DB 시험에 익명/Guest/남의 공개 글/CSRF/동의 누락/판 충돌/타 글 및 교체 전 첨부/URL 주입 거부 검사를 추가했다. 이 묶음은 Google을 호출하지 않는다.
3. 기존 공통 회귀와 `memories_runtime_browser.py`의 실제 PHP 화면 검사를 수행한다. 전체 공통 묶음은 20분 이상 걸릴 수 있다.
4. 격리된 공급자 대체 응답으로 실제 PHP의 요청 사진 바이트·설정 미등록·429/타임아웃·동일 요청 재전송·생성 중 글 수정/삭제·결과가 게시물을 바꾸지 않는지 확인한다. 일반 모아 Gemini 대화/문장 도구가 기존 한도를 공유하며 그대로 동작하는지도 확인한다.
5. 기존 서버 발행 절차로 새 PHP와 JS/템플릿·캐시 버전을 함께 반영한다. 운영 키를 복사하거나 Git에 넣지 않는다. 기존 모아 Gemini 설정의 활성 상태를 서버에서 확인한다. 이 클라우드가 현재 운영 설정을 확인했다는 뜻은 아니다.
6. 사용자 본인의 휴대폰에서 선택한 사진·메모로 실제 Gemini 초안을 한 번 생성하고 본문에 추가해 저장한다. 사진의 실제 모습과 문장이 맞는지, 원본 글·사진·공개 범위가 유지되는지 확인한다. 적용 커밋·검증 결과를 기록한다.

현재 사용자가 올린 남한산성 사진 자체는 클라우드에서 읽지 못했다. 이 문서나 합성 시험 문장을 사용자의 실제 사진에 근거한 완성 글로 안내하지 않는다.
