# 사진과 글의 이야기 구성

사용자 결정: 등록순 기본 + 재배치 제안. 과장된 감상문 대신 사진 전체의 연결과 간결한 문체, 사진 사이에 배치된 글을 원한다.

구현 범위: 최대10장, 원본 무변경/GD 참조용 축소, 번호별 이미지 근거, JSON 장면 구성과 엄격한 첨부 검증, 등록순 미리보기/재배치 제안 선택, 장면별 편집, 명시적 저장. 기존 caption·original_caption·original_media 보존. story JSONB 추가전용 migration. 사진 제거/교체 시 고아 장면을 남기지 않고 명시적으로 구성을 해제한다. 구형 클라이언트가 story를 생략하면 기존 구성을 보존하며 첨부 충돌은409로 거부한다.

허용 파일: MemoryAi.php, 신규 MemoryStory.php, Memories.php, memories.js/css/page, 새 migration·설치/검증 harness·시험·문서·위키. 기존 인증/CSRF/소유권/판검사/장부/외부전송 목적지는 유지한다.

프롬프트 참고: Google 공식 structured output 문서 https://ai.google.dev/gemini-api/docs/generate-content/structured-output?hl=en . API JSON Schema와 별도로 사진 대응·순서·중복·누락·길이는 서버에서 검증한다.
