## 동기화 (F-42, 2026-09-15 구현)

코드는 시각의 함수(스텝 = `시각 ÷ 30`)라 PC 시계가 어긋나면 화면의 코드가 서버에서 거부된다. 그래서 생성기는 **열릴 때 한 번과 그 뒤 5분마다** 서버에 시각을 물어 「서버 − PC」 차이를 구하고, 남은 초와 코드 계산에 그 차이를 더한다. 서버 시각을 파일에 박아 넣지 않는다(사용자 결정 2026-09-15).

**창구** — `GET /api/time` (`src/handlers/time.php`, 라우트 정책 `POLICY_PUBLIC`). 응답은 `{"now": <유닉스 초>, "now_ms": <유닉스 밀리초>, "period": 30}` 뿐이고(`now_ms` 는 보안 넷 2026-09-26 — `now` 는 그 몫 그대로) `Cache-Control: no-store` 다. 로그인·CSRF·감사 기록이 없다 — 읽기만 하고 대상이 없으며, 같은 값이 응답 헤더 `Date` 로도 이미 나간다.

**공식** — 보낸 때 `t0`, 받은 때 `t1`(둘 다 PC 시계), 응답 `now_ms`(밀리초 — 없으면 `now` × 1000, `serverMillis()`):

```
offset = now_ms + (t1 − t0) ÷ 2 − t1        (밀리초, 「서버 − PC」)
serverNow() = Date.now() + offset
```

왕복 지연의 절반을 더해 **답이 만들어진 순간**을 `t1` 에 맞춘다. `Date.now()` 는 `serverNow()`·`syncTime()` 안에서만 쓰고, `tick()` 과 코드 계산은 `serverNow()` 만 본다.

**갱신 박자** — `tick()` 은 `scheduleTick()` 이 잡는 `setTimeout` 으로 **다음 초 경계(서버 시각) + 20ms** 에 돈다(`TICK_SLACK`). 30초 스텝 경계도 초 경계라 코드가 경계 직후 바로 바뀐다. 시각을 다시 맞추면(`syncTime` 성공) 박자도 새로 잡고, 숨겨 둔 탭이 다시 보이면(`visibilitychange`) 바로 한 번 그린다. 전에는 `setInterval(tick, 1000)` 과 정수 초 `now` 때문에 경계 직후 1~2초 동안 이전 스텝 코드가 보였다(SECURITY R-79, 서버 창 0 에서 401).

**저장 키** — `localStorage['tbox-totp-offset'] = {"offset": <ms>, "at": <마지막으로 맞춘 때, PC 시계 ms>, "base": "<물어본 t-box 주소>"}`. 비밀 키는 이 값에 들어가지 않는다. 서버에서 **받는 것은 시각뿐이고 보내는 것은 없다**(SECURITY R-40 보충).

**상태 3종** (「시각 확인」 칸)

| 상태 | 언제 | 문구 |
|---|---|---|
| 맞춰짐 | 이번 화면에서 `/api/time` 응답을 받았다 | 「서버와 동기화됨 · 서버 시각 HH:MM:SS · PC 와 ±N초」 |
| 오프라인 · 보정값 | 서버에 닿지 못했지만 적어 둔 차이가 있다 | 「오프라인 · 저장된 보정값 사용(마지막 동기화 M분 전)」 |
| 오프라인 · PC | 한 번도 맞추지 못했다 | 「오프라인 · PC 시각 사용 — 코드가 틀리면 PC 시계를 맞추세요」 |

차이가 ±60초를 넘으면 상태 줄이 경고색이 된다.

**`file://` 처리** — 파일로 열면 `location.origin` 이 없어 물어볼 곳을 모른다. 그래서 상태 줄 아래에 t-box 주소 입력칸을 한 번 보여 주고(`https?://` 로 시작하는 값만 받는다), 적은 값을 `base` 로 저장한 뒤 맞추기를 시도한다. 서버에서 연 화면에는 이 칸이 없다.

**CORS 근거** — 생성기는 PC 에 받아 `file://` 로 여는 것이 전제라 출처가 달라진다. `/api/time` 이 내주는 것은 시각 하나뿐이라 다른 출처가 읽어도 잃을 것이 없어, `Access-Control-Allow-Origin: *`·`Access-Control-Allow-Methods: GET` 을 **이 핸들러에서만** 붙인다. 세션 쿠키로 내용이 갈리는 다른 응답에는 붙이지 않는다.

**CSP** — 생성기 전용 CSP(`deploy/sites/tbox-v2.conf` 의 location, 그리고 파일 안 `<meta>`)는 `default-src 'none'` 이라 어떤 연결도 막는다. 여기에 `connect-src 'self'` 한 칸만 더한다. `'self'` 라서 **이 서버 말고는 어디로도 보낼 수 없다** — 비밀 키가 새는 경로를 만들지 않는 것이 이 한 칸의 요점이다. 적용 전에는 fetch 가 막혀 상태 줄이 「오프라인」 이 되고, 그 상태에서도 코드는 PC 시계로 계속 나온다. 파일로 연 문서에는 `'self'` 에 해당하는 출처가 없으므로, 주소를 적어도 실제 맞추기는 CSP 를 그 주소까지 넓히는 결정이 있어야 동작한다(넓히면 「어디로도 보낼 수 없다」는 성질이 약해진다 — 미결).

**잠금 문구** — 최소 길이 12자(`MIN_PASS`). 안내는 「잠금 문구는 12자 이상이어야 합니다. 단어 2~3개를 권합니다.」

## 휴대폰 · 홈 화면에 추가 (F-46, 2026-09-15)

인증 앱이 광고·결제를 요구해 못 쓰는 사람을 위해 **휴대폰 브라우저**에서 쓰는 길을 열었다. 만드는 것은
앱(APK)이 아니라 **브라우저의 바로가기**다 — 스토어·권한·자동 갱신·결제가 없고, 지우는 것도 바로가기를
지우면 끝이다.

**화면** — `@media (max-width: 480px)` 한 블록이 전부다. `.wrap` 패딩 12px, 입력칸·버튼 100% 폭,
버튼 `min-height: 44px`(손가락 목표 크기), 입력 글자 16px(iOS 가 그보다 작으면 자동 확대한다),
코드 글자 40px, 긴 문자열은 `overflow-wrap: anywhere`. 전에 있던 `@media (max-width: 420px)` 의
「코드를 32px 로 줄인다」 규칙은 **없앴다** — 휴대폰에서 읽어야 하는 것이 그 코드이기 때문이다.

**매니페스트** — `public/assets/totp-generator.webmanifest`.

| 키 | 값 | 왜 |
|---|---|---|
| `name` · `short_name` | 「t-box 2단계 코드」 · 「t-box 코드」 | 홈 화면 아래에 짧은 이름이 나온다 |
| `start_url` · `scope` | `/assets/totp-generator.html` · `/assets/` | 바로가기를 누르면 생성기만 열린다 |
| `display` | `standalone` | 주소창 없이 앱처럼. 주소창이 없다는 점은 **피싱 관점에서 양날**이라 이름·아이콘을 t-box 로 고정해 둔다 |
| `theme_color` · `background_color` | `#1d5fbf` · `#f4f6f9` | 여는 동안의 색 |
| `icons[0].src` | **`data:image/svg+xml,…`** | 외부에서 받아오는 것이 **0**. 아이콘 하나 때문에 새 출처를 여는 일을 하지 않는다 |

`<head>` 에는 `<link rel="manifest">`·`<meta name="theme-color">`·`<link rel="apple-touch-icon" href="data:…">`
가 있다. iOS 가 SVG 아이콘을 못 읽으면 그냥 무시하고 화면 캡처를 쓴다 — 그래도 둔다(동작에 영향이 없다).

**CSP 한 칸** — `default-src 'none'` 아래에서는 매니페스트도 막히므로 `manifest-src 'self'` 를 더했다
(파일 안 `<meta>` 와 `deploy/sites/tbox-v2.conf` 의 생성기 location 둘 다). `'self'` 라서 성질은 그대로다:
**이 서버 말고는 어디에도 닿지 못한다.** 매니페스트 자체는 `location = /assets/totp-generator.webmanifest`
에서 `types { application/manifest+json webmanifest; }` 로 내보낸다(`add_header Content-Type` 은 헤더를
두 줄로 만들기 때문에 쓰지 않는다). 배포본(`/etc/nginx`)에 적용되기 전에는 Content-Type 이 달라
브라우저에 따라 매니페스트를 무시할 수 있고, 그때도 페이지는 정상 동작한다.

**보내는 것은 여전히 없다** — 휴대폰에서도 비밀 키·코드·잠금 문구는 그 브라우저 밖으로 나가지 않는다.
다만 **그 휴대폰으로 t-box 에 로그인하면** 기기가 다시 하나가 되어 R-40 의 조건이 그대로 돌아온다.

## 허용 창 (2026-09-15 사용자 결정)

- 서버 `Totp::verify/verifyStep` 기본 창을 **±1 스텝(±30초) → 0(현재 30초 구간만)** 으로 좁혔다. 생성기가 서버 시각과 동기화되므로 화면의 남은 초와 서버가 받는 구간이 같아진다.
- 대가: 시계가 몇 초 이상 어긋난 휴대폰 인증 앱은 「코드가 틀립니다」가 잦아질 수 있다(5회 실패 → 10분 잠금). 사용자가 이 위험을 수용.
- 재사용 차단(R-45)·1회성은 그대로.
