# 작업명

- 상태: 개발 중 / 클라우드 검증 완료·서버 검증 대기 / 서버 검증 완료·배포 대기 / 배포 완료 중 하나
- 작업 브랜치:
- 기준 main 커밋:
- 후보 커밋: (자기 커밋 해시를 본문에 넣으려고 반복 커밋하지 말고 인계 시 기록)
- 담당 환경: 클라우드 / 서버

## 목적과 범위

사용자가 요청한 결과와 변경 파일. 범위 밖 후속 작업도 적는다.

## 검사

명령, 종료 상태, 통과/실패 수, 증거 경로. PHP/DB/브라우저/실제 공급자/실물 기기를 구분한다. 미실행은 이유와 함께 적는다.

## 서버 적용

- DB 변경: 없음 또는 migration 파일·권한·순서·재적용 검증
- 패키지/설정/cron/서비스: 없음 또는 구체적 변경
- 기존 데이터 보존과 충돌 판정:
- 모의 적용과 실제 HTTPS 확인:
- 실패 시 대응: 이전 코드 복귀 가능 조건, 추가 스키마·새 데이터 보존. DB 삭제/복원 명령을 자동 실행하지 않는다.

## 배포 결과 (서버에서만 작성)

검증한 커밋/버전, 시각, 백업 확인, 실행 결과, 잔여 항목. 성공 후 `deploy/production-state.json`을 갱신한다.
