## 최종 변경

기존 OpenAI 토큰 HTTPS POST의 성공 응답에서만 인증서 검증, 정확한 URL/메서드, Date 형식, Age=0, 왕복5초 이하를 확인해 시간 표본을 얻는다. 서버 시각과 단조 시계를 메모리에 보관하며 보정 범위±5분, 표본 유효기간5분이다. 새 시간 서버 요청·TLS 우회·W32Time 설정·Windows 시계 변경은 없다.

PyJWT에 현재 시각을 전달할 공개 인터페이스가 없어 기본 시간 검사만 대체했다. 서명·알고리즘·키·issuer/audience·nonce·azp·subject를 먼저 확인한 뒤 exp/iat/선택 nbf의 숫자형·범위·만료·미래 여부를 같은 내부 시각으로 반드시 검사한다. 기존 여유5초는 유지한다. 토큰 iat에서 시간을 추정하거나 만료 검사를 생략하지 않는다. Windows 시간 설정 열기 버튼과 범위 밖 오류의 동기화·미완료 등록 재시도 안내를 추가했다.

기존 통합본의 요청별 timeout·stream_timeout·연결 정책·마감 엔진은 보존한다. 새 `fix-gpt-time.cmd`는 GPT 모듈3개를 한정 치환하고 시간 모듈1개를 추가한다. 기존 설치의 다른 코드·계정·설정·업무 자료·빌드 표시는 유지한다. 사전 SHA/구문/경로/실행 중 검사, 코드 백업, 원자 교체·실패 복구, 재실행 변경 없음이 있다. 알 수 없는 코드나 부분 보정 상태는 거부한다. 전체 업데이트용 기존 update.cmd도 유지한다.
