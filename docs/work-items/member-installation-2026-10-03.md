- 상태: 클라우드 검증 완료·서버 검증 대기
- 작업 브랜치: `cloud/community-member-experience`

- 후보 커밋: 전체 회원 경험 개선 묶음 인계 시 기록
- 담당 환경: 클라우드

## 목적과 범위

초대받은 회원은 비서 설치·토큰 발급 없이 시작한다. 모바일·PC에서 기존 모아 웹앱을 설치하는 안내와 브라우저 설치 버튼을 제공한다. 설치한 앱은 같은 출처의 로그인 세션을 사용하며 API 토큰을 발급·전달·브라우저 저장하지 않는다. iOS나 브라우저 프로필 분리로 로그인이 이어지지 않으면 기존 패스키/비밀번호 방식으로 로그인한다. 설치 자체가 로그인 유지나 Gemini 권한을 새로 부여하지 않는다.

새 파일: `src/views/member_install.php`, `public/assets/member-install.js`, `tests/member_install_browser.py`.
수정 파일: `src/views/member_top.php`(기존 매니페스트·설치 JS 포함), `src/handlers/member_welcome_page.php`(설치 안내·접힌 외부 토큰 설정), `src/views/member_local_buddy.php`(실제 ZIP·연결 조건). 인증 담당의 같은 두 회원 화면 변경과 함께 통합한다.

설치 이벤트는 클릭 이후에만 실행한다. 네이티브 설치 창이 없는 기기에서는 Android, iOS, PC의 브라우저 메뉴 안내를 제공한다. 설치 요청 수락과 완료 이벤트를 구분한다. 취소·오류 시 브라우저 사용을 계속할 수 있다. 카카오톡 등 내장 브라우저에는 외부 브라우저로 여는 방법을 안내한다. 서비스 워커·오프라인 개인 데이터 캐시를 추가하지 않는다.

Git2 확인 결과 별도 실행파일 릴리스/첨부물은 없다. `AI-비서(로컬)`의 고정 커밋 `f7caeb47f56f91720f645e635cb3a384bd64b665` 소스 ZIP은 권한 있는 Git2 계정으로 HTTP 200과 ZIP 서명 `PK`를 확인했다. 비인증 요청은 404여서 일반 초대 회원용 설치파일로 표시하지 않는다. 개발용 Windows Python/Tk 소스이며 Git2 권한과 별도 설치가 필요함을 안내한다. 이 공유본의 `chatgpt-deployment.json`은 `mode=unconfirmed`로 실제 ChatGPT 로그인·추론이 비활성이다. 웹 연결은 기존 일회용 코드·PC 승인으로 자격을 자동 교환하며 모아 업무 토큰을 입력하지 않는다. 업스트림 독립 제품 코드를 수정·재배포하거나 자격 상태를 변경하지 않았다.

## 검사

- `node --check public/assets/member-install.js`: 종료 0.
- `python3 tests/member_install_browser.py`: Chromium 실제 JS/화면 + 합성 설치 이벤트, 14개 통과, 종료 0. 사용자 클릭 전 설치 없음, Android/iOS/PC·내장 브라우저 안내, 모바일 가로 넘침 없음, 수락/완료 구분, 취소·오류 회복, standalone 상태, 토큰 발급/API 통신/영구 자격 저장 없음 확인.
- Git2 releases/branch/README/DISTRIBUTION/배포 자격 JSON 조회, 고정 ZIP 인증/비인증 다운로드 확인. 운영 서버에 요청하지 않았다.
- PHP가 없는 환경이어서 테스트의 PHP 부분 템플릿은 고정 URL만 치환했다. PHP 실행·운영 매니페스트·실제 브라우저 설치 자격·실물 휴대폰·Windows 설치·ChatGPT 공급자 로그인은 미검증이다. 모의 설치 이벤트를 실제 설치 검증으로 간주하지 않는다.
- `git diff --check` 해당 수정 파일: 종료 0. 전체 보안 린트·자산·위키 검사는 통합 담당이 최종 변경 기준으로 수행한다.

## 서버 적용

- DB 변경: 없음.
- 패키지/설정/cron/서비스: 없음. 기존 `/tbox/app.webmanifest`를 재사용한다. APK/EXE 배포물을 새로 만들지 않았다.
- 기존 데이터 보존과 충돌 판정: 사용자 세션·토큰·개인 기록을 수정하지 않는다. 회원 가입 인증 선택 변경과 회원 화면을 함께 검토한다.
- 모의 적용과 실제 HTTPS 확인: 시작 안내에서 로그인 선택 → 설치 또는 건너뛰기 → 커뮤니티/메신저 동작, 실제 Chrome/Edge 설치 메뉴, Safari 홈 화면 추가, 재로그인·로그아웃, 기존 외부 비서 토큰 발급을 격리 사용자로 확인한다. 개인 ChatGPT 독립 비서는 자격 미확인 상태를 유지한다.
- 실패 시 대응: 해당 화면/정적 자산을 이전 후보로 복귀할 수 있다. 사용자 데이터·DB 삭제/복원은 필요하지 않다.
