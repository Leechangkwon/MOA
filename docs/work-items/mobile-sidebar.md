## 목적과 범위

사용자 사진의 앱·계정 메뉴, 업무 메뉴, 최근·문서 트리가 한꺼번에 펼쳐지는 문제를 고친다. 960px 미만에서는 ☰와 앱 이름이 각각 현재 앱 내비/앱·계정 메뉴만 열며 서로 전환한다. 브랜드·바로가기 중복을 줄이고, 보조 목록은 기본 접힘·한 묶음씩 펼침. 닫기와 Escape는 상단 단추에 초점을 돌려준다. 넓은 화면의 기본 펼침은 유지한다. 숨은 트리의 비동기 로딩은 서랍을 스크롤하지 않는다.

수정 허용: src/views/shell_top.php, public/assets/app.js, public/assets/app.css, public/assets/community/editor.js와 자동 자산 버전 참조, tests/community/qf12_shell_browser.py, DESIGN.md, STAGES.md, SECURITY.md, 이 문서, wiki/qaredi/guide-site.json·index.json, 발행/배포 기록. 라우트·Authz·DB·API·실제 문서 내용은 변경하지 않는다.

## 검사와 반영

기존 격리 셸 브라우저 시험에 모바일 분리/접기/키보드/반응형 전환/늦게 오는 목록 회귀를 추가하고 공통 UI·정적 검사를 수행한다. 백업/복호화 → 파일 모의 적용/드리프트 → 코드 반영 → 실제 HTTPS 모바일·PC 확인 → 데이터 보존 기록. DB/패키지/서비스 설정 변경0. 실패 시 자료 삭제·복원 없이 원인을 확인한다. 실물 휴대폰 재확인은 사용자에게 남는다.
