## 목적과 범위

하위 작업을 연 상세창에 상위 항목 링크가 없어 되돌아가기 어려웠다. 서버가 이미 읽기 권한을 확인해 반환한 page.parent를 사용해 제목 위에 「‹ 상위 항목 · 제목」을 표시한다. 오른쪽 상세창에서는 같은 창 안에서 이동하고, 전체 화면은 기존 페이지 경로의 상위 링크를 유지한다. 주소 직접 열기·새로고침에도 작동하며 브라우저 뒤로/앞으로와 수정키 새 탭 열기를 유지한다. 프로젝트 행은 기존 프로젝트 이동을 유지하고, 부모가 없거나 볼 수 없으면 링크를 그리지 않는다. 편집 중 새 링크를 누르면 저장을 기다리고, 저장 오류 때는 현재 편집기를 남긴다.

변경: work.js, app.css, 자산 버전, 기능 수락 시험과 관련 기록. API·DB·권한 판단·기존 사용자 문서는 변경하지 않는다. 기존 다른 이동 동작의 편집 처리 전면 개편은 범위 밖이다.
