## 목적과 범위

사용자는 모아 서비스의 시작·완료 기능·개발 과정·예정 과제를 프로젝트 작업글로 관리하려 했다. 기존 도구가 문서 갱신만 지원한다는 이유로 프로젝트 뿌리 본문에 몰아 썼고 작업 목록이 비었다. 사용자의 지적(2026-10-17)에 따라 원래 문서를 보존하고 항목별 작업글로 등록한다.

위치 제한 없는 옛 생성 창구를 확장하지 않는다. 새 업무 생성 창구는 읽고 편집할 수 있는 프로젝트의 직계 작업만 만든다. 계정/소유권/공유/범위·부모 임의 변경은 받지 않는다. 부모의 기존 권한·범위를 따르고, 기존 삽입/파생 색인/감사 경로를 재사용한다. 읽기 토큰 및 읽기 공유는 거부한다. 명시적 요청 UUID로 재전송 중복을 막으며 다른 본문·부모·변경된 작업에는 409로 답한다. 업무 읽기에 프로젝트 섹션 선택지를 함께 제공한다. DB migration·설정·패키지 변경 없음.

수정 허용: `src/community/{WorkDocuments.php,forms_helpers.php,routes.php}`, 새 `handlers/work_document_create.php`, `src/mcp/McpTools.php`, `clients/mcp` client/server/시험/안내/버전, 새 수락 시험과 하네스 허용 목록, API/ARCHITECTURE/SECURITY/STAGES/발행/운영 기록. 요청 밖 데이터·Rea_ERP·기존 본문 변경 없음.
