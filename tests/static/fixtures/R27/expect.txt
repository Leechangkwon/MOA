#   quiet_n1              전부 다시 적기 · 조각 include · 앱으로 넘기는 블록(skip) · 보안 헤더 없는 server — 0

#   fire_n3               http 단 gzip_types 의 application/json(1) · location 의 application/problem+json(1)

#   quiet_n3              정적 자산 형식만(manifest+json 포함) · 같은 블록 gzip off — 0
#   fire_n4_regex         정규식 alias 가 `(.+)` · `(?<name>[^?]*)` 캡처를 이음(2)
#   fire_n4_slash         접두 location 끝 / 없음 × alias 끝 /(1)
#   quiet_n4              좁은 캡처 · 끝 / 짝 · ^~ · 정확 일치 · 캡처 안 쓰는 정규식 alias — 0
#   fire_n5               상대 return 301 · rewrite permanent 에 absolute_redirect off 없음(2)

#   quiet_n5              server 단 off 상속 · 절대 주소 · $scheme · rewrite last · ssl 만 듣는 server — 0
#   fire_n6               공개용·로컬용: expires 값 다름(1) · limit_req 로컬에 없음(1) · 끝 슬래시 블록 공개에만(1)
#   fire_n6_server        server 단 client_max_body_size(1) · X-Frame-Options(1) · location 의 internal(1) — HSTS 는 비교 밖
#   quiet_n6              루프백 평문 로컬의 HSTS 없음 · access_log·listen 차이 · qcheck-allow 표식 — 0
#   fire_n7_slash         끝 슬래시 변형 없음(1) · 변형의 zone 다름(1)
#   fire_n7_zone          정의 없는 limit_conn zone(1) · limit_req zone(1)
#   quiet_n7              정의된 zone · 같은 zone 변형(중첩 location 안 포함) · 정규식 location — 0
